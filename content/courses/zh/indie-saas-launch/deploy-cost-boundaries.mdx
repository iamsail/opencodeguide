免费额度不是「多少钱以内不要钱」，而是几种不同的计量各自有一个上限，你只会先撞到其中一个。搞不清是哪一个，账单来的时候会以为平台在乱收费。

## 四种计量，四个不同的天花板

请求数、计算（函数调用次数、CPU 时间或机器小时）、出口流量、构建次数与时长。静态站的边际成本主要落在请求与流量上；带 SSR 的站会先撞计算；有后台任务的会先撞机器小时。

判断方法很土但有效：把站点按「静态页 / 需要运行时 / 需要常驻进程」分类，写下每一类大概的量级，然后只看会先达到上限的那一项。一个月几百次访问的站，讨论带宽是没有意义的。

## 差异在「什么会突然变贵」

| 维度 | Vercel | Cloudflare（Pages / Workers） | Fly.io |
| --- | --- | --- | --- |
| 主要计费轴 | 函数调用、带宽、构建 | 请求数与 CPU 时间 | 常驻机器小时与卷 |
| 纯静态站 | 支持，构建与预览体验最好 | 支持，边际成本最低 | 需自己接 CDN，机器常驻 |
| 需要常驻进程 | 平台 Cron，长任务需外部队列 | Cron Triggers、Queues | 最自然 |
| 冷启动 | 视运行时与区域 | Worker 冷启动短 | 机器常驻则没有 |
| 数据库 | 需外部托管 | D1，或外部 Postgres | 可与应用同机或外接 |
| 一个人维护成本 | 低，接上 git 就部署 | 中，要学 wrangler 与绑定 | 高，Docker、区域、健康检查 |
| 适合条件 | 要预览环境、一体化体验 | 静态为主 + 少量边缘逻辑 | 长连接、后台任务、需要固定运行时 |

三个平台都能跑你的站，真正的分野是「谁替你处理了运维」。Vercel 把构建和预览替你做了，代价是动态行为会直接变成函数调用；Cloudflare 的静态几乎不要钱，代价是配置模型学一遍；Fly.io 给你一台真的机器，代价是这台机器归你维护。

## 在账单之前发现问题

三个命令足以做一次自查，不需要接监控。缓存没命中是最常见的隐性成本来源——每个请求都回源，流量和计算都会翻倍。

```bash
# 1) 静态页是否命中 CDN 缓存（第二次请求应出现 HIT 或 age > 0）
curl -sI https://your-domain.com/zh/courses \
  | grep -iE 'x-vercel-cache|cf-cache-status|^age:'

# 2) 请求是否落到了函数/边缘运行时（会带区域信息与 ray id）
curl -sI https://your-domain.com/zh/courses \
  | grep -iE 'x-vercel-id|cf-ray'

# 3) 构建产物体积与文件数：出口流量和构建时长的先行指标
du -sh out/ && find out -type f | wc -l
```

第一条没有输出，说明缓存头没配对，先修这个再谈优化。仓库的课程站连函数调用都省了：静态导出加上独立的 Webhook Worker，站点侧不会因为流量增长产生计算费用。

## 一个人的最小组合

最小可行版本是三段式：静态站放 CDN，Webhook 与邮件放一个 Worker，数据库托管。这个组合的好处是每一段都能单独迁走，任何一段涨价只影响一段。

什么时候不用做这套：还没上线、也没人访问时，选部署最省事的那个平台就够了，把域名和支付先跑通。什么时候必须重新算：看到账单里出现你预期之外的计量项，或者某个功能的实现方式（图片优化、中间件、定时任务）开始依赖平台特性。

## 落地动作

1. 把上面三条 `curl` 换成自己的域名跑一遍，记录缓存是否命中、响应头里有没有函数标记。
2. 在账单页把「本月实际用量」按计量项抄成一行数字，与免费额度或套餐上限逐项对照，标出最接近上限的那一项。
3. 在对比表里补一列「每月运维小时数」，按自己的时间成本折算成钱。只为省几美元搬家的结论，多半在这一列被推翻。

## 常见坑

- **现象**：站点明明是静态的，账单里却有函数调用。 → **原因**：图片优化、中间件或某个动态路由，任意一个都会让请求进入运行时。 → **对策**：静态导出加 `images.unoptimized`，中间件改为纯客户端逻辑，动态部分挪到独立 Worker。
- **现象**：流量费用超过托管费用本身。 → **原因**：把视频、大图、安装包放在应用域名下，每次下载都算出口流量。 → **对策**：媒体放对象存储（如 R2）或外部托管，页面只承载文本与样式。
- **现象**：为了省每月的托管费把站搬到需要自己运维的平台，第二周开始修 Docker 和证书。 → **原因**：只算了托管费，没算运维时间。 → **对策**：把「每月花在这台上的小时数 × 你的时薪」写进对比表，再决定搬不搬。
