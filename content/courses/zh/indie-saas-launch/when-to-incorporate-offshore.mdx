注册一个海外公司只要几天，养它要每年。多数人算的是注册费与代办费，漏掉的是年审、记账、报税、注册地址、银行账户最低余额，以及「有了主体，合规就再也不能暂停」这件事。

## 先算持有成本，再谈注册地

成本项固定几块：注册与首年秘书、注册地址续费、年审、记账与报税（部分辖区还要审计）、银行账户最低存款或月费、某些辖区强制的本地董事服务。全部用你拿到的报价单填，价格随代理与服务范围变化很大。

```bash
set -euo pipefail
# 全部填你自己的报价，单位统一为当地货币
REGISTRATION=0        # 注册 + 首年秘书/注册地址
ANNUAL_RENEWAL=0      # 年审 + 秘书 + 注册地址续费
BOOKKEEPING=0         # 记账与报税（含年度报表）
BANK_COST=0           # 银行最低存款占用或月费 × 12
EXTRA=0               # 提名董事、审计、代办年检等

ANNUAL=$(awk -v a="$REGISTRATION" -v b="$ANNUAL_RENEWAL" -v c="$BOOKKEEPING" \
             -v d="$BANK_COST" -v e="$EXTRA" 'BEGIN{printf "%.0f", a+b+c+d+e}')
MARGIN=0.85           # 扣掉支付通道与基础设施后的毛利率，用你自己的数据
echo "首年持有成本: $ANNUAL"
echo "按毛利率 $MARGIN 计，覆盖成本需要年流水约 $(awk -v a="$ANNUAL" -v m="$MARGIN" 'BEGIN{printf "%.0f", a/m}')"
echo "留三倍安全边际，目标年流水 $(awk -v a="$ANNUAL" -v m="$MARGIN" 'BEGIN{printf "%.0f", 3*a/m}')"
```

三倍不是行业标准，是经验判断：收入波动、汇率、一次申报失误的补救成本，都在这条缓冲里。把结果写进 `docs/entity-decision.md` 并记下日期，一年后重算。

## 四条路径的账

| 路径 | 适用条件 | 年维护动作 | 代价与风险 |
| :--- | :--- | :--- | :--- |
| 不注册，走 MoR 平台 | 还在验证，流水低于持有成本 | 无，平台代收代缴 | 抽成高，发票主体不是你，定价与退款受平台规则约束 |
| 香港公司 | 客户分散全球，能接受每年审计与报税 | 年报、商业登记续期、利得税报税、记账 | 离岸豁免要申请并举证业务实质；实际管理在内地，可能被认定为中国居民企业而就全球所得纳税 |
| 美国 LLC（Wyoming、Delaware 等） | 客户主要在美国，需要美国银行与支付通道 | 注册代理续费、州年度报告、联邦与州申报 | 非居民有美国来源收入时涉及 ECI 与预扣税表；外资持股的 LLC 还有 5472 等申报，漏报罚款远高于注册费 |
| 新加坡公司 | 要东南亚落地与本地银行，愿意配本地董事 | ACRA 年报、税务申报、本地董事服务 | 必须有本地常驻董事，通常要买提名服务；合规成本高于香港 |

最容易被低估的是开户：代理一周能交付注册证书，账户审核看的是业务真实性——站点、客户、流水、合同。开户失败时，你手上只有一个空壳公司和一张每年都要续的年审账单。

## 四个信号说明该动手了

支付通道受限：payout 被延迟、账户被要求补充材料、或平台直接限制业务类型。企业客户要求：对方要以公司名义签合同、开票、签数据处理协议。收入稳定：年流水已是持有成本的三倍以上，注册不再挤压利润。业务需要本地化：必须有本地银行账户、本地支付方式或本地办公地址才能接单。

反过来，四种情况别动手：还没验证有人付钱；年流水低于持有成本的两倍；只有国内客户，多一个主体只多一套申报；有全职雇佣合同且没确认竞业条款与税务居民身份是否变化。最后一条最容易被忽略，也最难补救。

## 最小可行版本

真要注册，先做「一主体、一本账、一张卡」：一个辖区、记账与报税外包、一个能收款的银行账户。起步阶段不要做多主体架构，一个主体加多币种收款就够用。多主体解决的是税务优化与风险隔离，有稳定利润后再付费讨论。

选注册地看三件事，而不是看注册费：银行能不能远程开户、每年的申报能不能不靠人盯、利润怎么合法回到个人手上。第三条决定分红、薪酬与个人税务居民身份的关系，注册前就要问清。

## 落地动作

1. 跑上面的脚本，把年持有成本与目标流水写进 `docs/entity-decision.md`，注明报价来源与日期。
2. 给三条路径各写一句「我不选它的原因」，写不出来说明还没调研够，别急着提交注册。
3. 用 MoR 或预售跑满一个季度，记录真实流水与退款率，再看三倍门槛是否达到。
4. 真要注册前先确认两件事：拟注册地是否要求本地董事或秘书，个人税务居民身份是否受注册地影响。这两条通常需要专业意见，一次咨询比一次补税便宜。

## 常见坑

- **现象**：公司注册好了，Stripe 账户还是过不了 → **原因**：注册主体只是必要条件，KYB 还要看业务真实性与可访问的站点、政策页 → **对策**：先把产品页、定价页、条款与退款页挂上去，再提交账户审核。
- **现象**：每年年审都靠代理提醒，忘一次就被罚 → **原因**：把年审当成一次性任务，没有本地日历 → **对策**：注册当天就把年报、报税、商业登记续期写进日历并提前一个月提醒，责任落在自己身上而不是代理的邮件里。
- **现象**：以为注册就少交税，结果两头都要申报 → **原因**：公司的税务居民身份与实际管理地不一致，利润汇回个人时还有一层 → **对策**：注册前把「公司所得税」与「利润回到个人」两条路径一起问清，别只比较注册地的名义税率。
