关键词工具只回答「多少人在搜」，不回答「搜的人想干什么」。同一个词根，`what is x`、`x vs y`、`x pricing` 背后是三种读者，而你只有一种页面模板时，只能承接其中一种。更常见的是：拿教程文去接 `x pricing`，排名上去了，注册是零，然后被记成「SEO 没效果」。

意图不是给关键词贴标签，是决定页面形态、内容顺序和唯一 CTA 的东西。

## 四种意图对应四种页面形态

| 意图 | 典型 query 形态 | SERP 顶部占位是什么 | 你该给的页面 | 唯一 CTA |
| :--- | :--- | :--- | :--- | :--- |
| 导航型 | 品牌名、品牌名 + 登录/文档 | 官网首页、官方文档、应用商店 | 品牌落地页或文档入口 | 进入产品 / 打开文档 |
| 信息型 | what / how / why / 报错原文 | 百科、博客教程、论坛问答、视频 | 教程或解释文，带步骤与示例 | 读下一篇 / 订阅 |
| 商业调查型 | best / vs / alternatives / review | 对比文、榜单、评测站、社区讨论 | 对比表 + 选型标准 + 适用人群 | 试用 / 看定价 |
| 交易型 | buy / pricing / 免费下载 / 注册 | 官方定价页、商品页、应用商店 | 定价页、商品页、注册页 | 立即购买 / 注册 |

这张表是判定基准，但不能凭感觉填。同一句 `best x for small team`，换个市场、换一年，SERP 顶部可能是第三方榜单，也可能是官方对比页——你要看的是当下真实的结果页。

## 判定看 SERP 占位，不看词根

流程三步，做完才允许动笔：

1. 用无痕窗口，把语言和地区切到目标市场，搜索目标词。
2. 数前十条结果的类型：博客 / 工具 / 分类页 / 商品页 / 论坛 / 视频，各占几条。
3. 占比最高那类就是搜索引擎当前认可的承接形态；你的页面向它靠，内容和体验再往上做。

补充检索式用来确认需求密度：`关键词 site:reddit.com` 看真实讨论里的用词，`关键词 intitle:vs` 看对比内容的供给量，`关键词 "pricing"` 判断需求是否已进入比价阶段。

把判定落成可复核的表，而不是记在脑子里：

```csv
keyword,serp_top_type,serp_mix,intent,page_type,cta,priority
"best crm for agency",comparison,"6 榜单 / 3 官网 / 1 论坛",commercial,comparison-table,trial,P1
"crm pricing",pricing,"7 官网定价 / 2 评测",transactional,pricing,start-trial,P1
"how to migrate crm data",tutorial,"9 教程 / 1 视频",informational,guide,subscribe,P3
"acme login",official,"9 官网 / 1 应用商店",navigational,login-entry,open-app,P0
```

`serp_mix` 必须写。只写 `intent=commercial` 的表，一周后你自己也复核不了。

## 一个页面只承接一种意图

混意图是内容站最常见的浪费：教程页底部塞定价模块，读者还没被说服就被要求付款；商品页里写三千字科普，把购买按钮推到屏幕外。规则可以简化成一句：信息页的 CTA 放在结论之后，商业调查页的 CTA 紧跟对比表，交易页除了价格、信任和结账路径，其余全砍。

还有种隐性混意图：同一个关键词写「教程 + 工具 + 报价」的全能页。它对哪种意图都不是最优答案，通常排不过专一的页面。

## 意图决定内容放在哪一层

本站是静态导出的 Next.js 站点，正文分布在 `content/` 下的 MDX 与 `app/**/page.mdx`，docs 区有独立侧边栏。这套结构本身就是意图分层：`app/(zh)/zh/docs/**` 承接信息型与部分导航型需求，`app/(zh)/zh/courses/[slug]` 承接商业调查与交易，`content/courses/zh/**` 的课时正文吃长尾信息型。

## 落地动作

1. 从 Search Console 导出近 90 天有点击的查询，按上表给前 20 个词填写 `serp_top_type`、`serp_mix`、`intent`。
2. 每个意图各挑一个词，把 SERP 前十条的页面类型截图存进同一个文件夹，作为团队判定基准，省掉下次争论。
3. 在现有页面里找出 CTA 与意图不匹配的三篇（信息页硬塞购买、交易页没有价格），改页面形态或改 CTA，二选一。

## 常见坑

- **现象**：教程文排到第一页，注册数不动。→ **原因**：该词 SERP 顶部是工具与模板页，读者要能直接用的东西，不是解释。→ **对策**：改成「教程 + 可下载模板」，文首就给产物，CTA 放在产物之后。
- **现象**：同一篇既想接 `x` 又想接 `x vs y`。→ **原因**：怕拆开分权重。→ **对策**：主页承接一个意图，另写一篇专做对比，两篇首屏互链并指向同一个转化页。
- **现象**：判定表和实际排名长期不符。→ **原因**：只查了一次 SERP，没按季度复核。→ **对策**：把 `serp_mix` 留在表里，每季度重跑一遍前 20 个词，变化的词单独标记再改页面。
