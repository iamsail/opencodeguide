做 SEO 三个月后最难受的阶段是：每天有曝光、每周有几笔注册，却说不清这笔投入值不值。这时候容易走两个极端——因为「SEO 是长期主义」继续加码，或者因为「三个月没起色」直接全停。两种决定都没有数据支撑，只是情绪的两面。

判断需要两类指标：一类证明流量在长大，一类证明流量能赚钱。只盯第一类会做出一个很大的穷站，只盯第二类会在资产没成型时提前放弃。

## 先定义，再判断

指标最容易被玩坏的是口径。同一句「月自然流量」可以指会话、点击或独立访客，能差一倍。所以每个指标写清分子、分母、数据来源，写不到可复算就不要进记分卡。

另外，所有指标先排除品牌词：品牌词点击来自你已建立的名字，混进来会让 SEO 看起来比实际好。

## 六个指标：三个看增长，三个看单位经济

| 指标 | 计算公式 | 数据来源 | 判读动作 |
| :--- | :--- | :--- | :--- |
| 非品牌自然点击 | `效果报表点击总量 − 品牌查询点击` | Search Console | 连续两月不涨，先查收录与内链 |
| 关键词覆盖数 | 平均排名优于自设目标线的查询去重数 | Search Console | 覆盖涨、点击不涨，转做内链与外链 |
| 自然注册率 | `自然来源注册数 ÷ 自然来源会话数` | GA4 | 低于上季，先看落地页与首屏 |
| 注册到付费转化 | `自然新增付费用户 ÷ 自然注册数` | GA4 + Stripe | 低于上季，问题在产品与定价 |
| SEO 获客成本 | `(内容工时 × 时薪 + 工具与外链费用) ÷ 自然新增付费用户` | 成本表 + Stripe | 高于付费渠道，SEO 此刻没有优势 |
| SEO 回本周期 | `SEO 获客成本 ÷ 每付费用户月毛利` | 同上 | 长于愿等的月份数，就缩小投入 |

前三个衡量资产是否在长大，后三个衡量生意是否算得过来。

## 用记分卡代替争论

把这些指标放进按季度填的表，每格只填数字和一句原因。表填不满，说明数据管道还没建好，此时谈策略是空的。

| 指标 | 上季度 | 本季度 | 变化 | 结论（加码 / 维持 / 收缩） |
| :--- | ---: | ---: | ---: | :--- |
| 非品牌自然点击 | | | | |
| 关键词覆盖数 | | | | |
| 自然注册率 | | | | |
| 注册到付费转化 | | | | |
| SEO 获客成本 | | | | |
| SEO 回本周期 | | | | |

阈值自己定，但要在看数之前定。例如「非品牌点击连续两季不增长」与「获客成本高于付费渠道」同时成立，就该把预算转到已有页面的转化上；反过来，点击在涨而获客成本仍低于付费渠道，说明资产在复利，增加投入是理性的。

## 什么时候该停

停的条件要可观测。三条够用：非品牌点击连续两季没有净增长；自然注册率连续两季下降且改过落地页仍无改善；SEO 获客成本高于你在跑的任何一条付费渠道。三条同时成立，就把 SEO 降级为「只维护已有排名」。

提前半年判断「不值得继续」，比多写三十篇没人看的文章更值钱。

## 落地动作

1. 把六个指标的定义、分子、分母、来源写成一段话放进团队文档，让第二个人独立算一遍，对不上先修口径。
2. 在 GA4 与 Search Console 各存一个固定视图（排除品牌词、固定自然月），每季度第一周导出填表。
3. 看数前写下本期三条停手条件，季度末只对照它做决定，中途不改。

## 常见坑

- **现象**：流量在涨、收入没动，团队说「再等等」。→ **原因**：只追踪点击与注册，付费链条没接上。→ **对策**：把付费转化与获客成本补进记分卡，缺数据先补埋点。
- **现象**：换口径后所有指标同比都变好。→ **原因**：中途改了会话定义或去掉品牌词过滤。→ **对策**：口径变更留记录，并从变更季度重新起算。
- **现象**：获客成本算出来极低，看着很划算。→ **原因**：只算现金支出，没算自己的写作时间。→ **对策**：把工时按时薪折成成本计入分子再判断。
