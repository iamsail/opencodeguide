季度末最常见的复盘是一场会说：「这个季度我们发了十二篇文章，流量有增长，下季度继续加油。」没人知道哪两篇带来了八成新增点击，也没人知道那篇写了三周的长文该不该留。会开完，下季度选题还是当天早上临时想的。

复盘要产出的是下季度写作清单：哪几篇更新、哪几篇合并、哪几篇下线、哪几个新选题排队。

## 复盘只回答三个问题

一：对照上季度目标，实际发生了什么。二：差异来自曝光、位置还是点击率。三：下季度只做哪三件事。

最容易糊弄的是第二个。把变化拆成 `曝光 × CTR × 位置`，就能定位：曝光涨而点击不涨是位置问题；位置稳定而点击下降是标题与摘要问题；曝光下降才去看收录与竞争。

## 复盘模板：一格只填一个事实

| 项目 | 上季度目标 | 实际 | 差异原因 | 下季度动作 | 负责人 | 截止 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 非品牌自然点击 | | | | | | |
| 自然注册数 | | | | | | |
| 注册到付费转化 | | | | | | |
| 付费订单对账差异 | | | | | | |
| 内容产出（篇） | | | | | | |
| 新增可用关键词数 | | | | | | |

「付费订单对账差异」最常被漏掉，它唯一能暴露「GA4 看起来很好、Stripe 收得很少」：`GA4 purchase 笔数 ÷ Stripe 成功支付笔数`。差异变大先修埋点，别急着加内容预算。

## 页面取舍：保留、合并、下线

复盘的价值一半在删。把上季度页面按「点击」与「是否指向转化页」过一遍：有排名也有转化路径的保留更新；同一意图的重复页面合并成一个主页面；长期零点击又没有内链的下线。

静态站的硬约束：GitHub Pages 不能配服务端 301。所以下线别直接删文件——先加 `noindex` 并从 sitemap 生成脚本里移除，保留一个指向新页面的链接，等旧 URL 被清掉再删。直接删会留一堆 404，比留着更伤。

## 排期按产能倒排，不按灵感正排

先算产能：每周能投入的写作与校对工时，扣掉改稿返工，得出真实能上线的篇数。多数团队会高估一倍。

排期顺序固定三步：先更新已有点击的老文（改标题、补内链、加本季度数据），再写覆盖已有关键词的补位文章，最后才是全新选题。老文的边际收益通常高于新文。

| 周次 | 内容 | 目标查询 | 意图 | 内链指向 | 状态 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| W1 | 更新：上季度点击最高的 3 篇 | 已有主查询 | 信息 | 课程详情页 | 待改稿 |
| W2 | 新增：补位长尾 2 篇 | | 商业调查 | 购买页 | 待写 |
| W3 | 合并：两个同意图页面 | | 信息 | 保留主页面 | 待重定向 |
| W4 | 新增：一个可链接资产 | | 导航 | 首页 | 待设计 |

每行必须写「内链指向」——没有内链的文章没有资格参与排名竞争。状态列只允许三种值。

## 落地动作

1. 复制模板成本季度文件，先补上季度目标，再填实际数字，差异原因只写一句，写完再开会。
2. 导出上季度全部页面的点击与曝光，按规则标注保留、合并或下线，产出带 URL 的清单。
3. 用真实工时算每周产能，把清单填进排期表，前四周只排「更新 + 补位」。

## 常见坑

- **现象**：复盘会开两小时，结论是「继续努力」。→ **原因**：表里只有目标与实际，没有差异原因和负责人。→ **对策**：每行填到「谁、做什么、什么时候完成」，填不出说明不该进表。
- **现象**：排了十二篇，实际交付四篇。→ **原因**：按理想产能排期，没扣改稿与设计返工。→ **对策**：用上季度真实交付数乘折损系数当上限，排不满的留白。
- **现象**：下线几篇后整站点击反而下降。→ **原因**：删掉的是还在贡献内链权重的页面，也没留跳转。→ **对策**：先 `noindex` 并保留链接，观察一季再删，同时把内链改指新页面。
