内链失败通常不是「链得少」，而是「链得随意」：底部一排「相关文章」由标签自动生成，全是指向同层的兄弟页；首页链向所有文章，文章谁也不链回分类。结果是每篇都在自己攒权重，谁也没把权重送到能收钱的那一页。

内链是站内唯一完全由你控制的权重分配手段。它不花钱、立刻生效、可回滚——但前提是你把它当结构设计，而不是当装饰。

## 三层分工：枢纽、支撑、转化

| 层级 | 页面例子（本站） | 职责 | 出链方向 |
| :--- | :--- | :--- | :--- |
| 第一层 枢纽页 | `/zh/courses/global-site-seo`、docs 的某个章节首页 | 覆盖主题全貌，接头部关键词 | 向下链全部支撑文，平级链相关枢纽 |
| 第二层 支撑文 | `content/courses/zh/global-site-seo/*.mdx`、单篇教程 | 吃长尾、承接信息型意图 | 向上链所属枢纽，横链 1–2 篇兄弟，向下链 1 篇转化页 |
| 第三层 转化页 | 定价页、课程详情页、注册页 | 收商业调查与交易意向 | 只链回 1–2 篇最硬的证据文与枢纽 |

关键约束是方向：支撑文必须**向上**和**向钱**发链接，转化页不要反向链一堆文章把读者带走。

## 每篇支撑文只发三类链接

一篇正文 3–8 条内链足够，三类链接各有位置：

| 位置 | 链到哪 | 锚文本 | 数量 |
| :--- | :--- | :--- | :--- |
| 首段或结论块之后 | 所属枢纽页 | 主题名（如「出海 SEO 内容生产系统」） | 1 |
| 正文中段、论证需要时 | 兄弟支撑文 | 对方解决的具体问题 | 1–2 |
| 结尾 CTA 之前 | 转化页 | 动作短语（如「看课程大纲」） | 1 |

锚文本写目标页解决的问题，不写「点击这里」「了解更多」。全站锚文本高度重复会被当成模板化链接，也帮不了目标页判断主题。

矩阵落成表，谁写新文章都按表发链：

```csv
from,to,anchor,position,priority
"guide/migrate-crm-data","hub/crm-guides","CRM 数据迁移完整指南",after-intro,P0
"guide/migrate-crm-data","compare/crm-for-agency","适合代理商的 CRM 对比",mid-body,P1
"guide/migrate-crm-data","pricing","查看定价",before-cta,P0
"hub/crm-guides","guide/migrate-crm-data","迁移步骤与字段映射",list,P0
"pricing","guide/migrate-crm-data","先看迁移成本",faq,P2
```

## 链接要长在正文里，不要长在页脚

页脚全站链接把同一个链接重复到每一页，搜索引擎会折算成一条，权重被稀释得几乎为零，还挤占正文链接的位置。

真正有效的内链是段落内的：读者读到「这一步之前要先确认字段映射」，紧接着给一个指向字段映射教程的链接。

另外两条硬规则：不要链到重定向链、不要在正文里链 noindex 页、不要让一篇文章的出链全部指向自己所在的列表页。

## 用仓库结构固化它们

这个站的课表顺序来自 `content/courses/*.json` 的 `modules`，侧边栏由它生成；`content/courses/zh/**` 的正文是 MDX，可以直接写站内相对链接；docs 区在 `app/(zh)/zh/docs/**`，已有侧边栏体系。改结构的正确顺序是：先定枢纽页，再定每篇支撑文属于哪个枢纽（写进 JSON 的模块归属），最后在 MDX 正文里补三类链接。

自查孤儿页只要一条命令：

```bash
# 列出正文里一条内链都没有的 MDX 文件（孤儿页候选）
find content/courses/zh app -name '*.mdx' -print0 \
  | xargs -0 grep -L '](' \
  | sort
```

反过来查「谁链到了转化页」：

```bash
grep -rl '/zh/courses/global-site-seo' content app --include='*.mdx' | sort
```

## 落地动作

1. 打开站点地图，把页面按三层归类，写进一张表；归不进任何一层的页面，先考虑合并或删除。
2. 按上面的 CSV 建内链矩阵，先只覆盖转化页相关的 10 条，逐条在 MDX 正文里落地。
3. 跑一次孤儿页检查，给结果里前 10 个页面各补一条「向上」链接。

## 常见坑

- **现象**：所有文章都有内链，转化页排名还是不动。→ **原因**：链接都在同层互指，没有一条指向转化页。→ **对策**：在矩阵里强制规定每篇支撑文必须有一条指向转化页的链接，位置在 CTA 之前。
- **现象**：内链加了，读者停留时间反而下降。→ **原因**：首段就往外链，读者还没读到内容就走了。→ **对策**：首段只留枢纽页链接，往外走的链接放到论证需要的位置。
- **现象**：改完内链，排名几周没反应。→ **原因**：只改了正文，没被重新抓取；或链接指向了重定向。→ **对策**：用 Search Console 的网址检查确认抓取，逐个点开新加的链接确认 200 且无跳转。
