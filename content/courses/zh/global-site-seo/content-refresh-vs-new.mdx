新站最常见的循环是：这周写三篇新文，下周再写三篇，半年后有两百篇，全部排在第二、三页。每篇都差一口气，但没有一篇被改过。

翻新之所以划算：老文已经有排名基础、有外部引用、有抓取历史，你只需要把缺的那块补齐；新文要从零建立相关性，还要等被发现。

## 先算清楚两种投入的差别

| 维度 | 写新文 | 翻新老文 |
| :--- | :--- | :--- |
| 启动成本 | 选题 + 调研 + 写作 | 读旧文 + 补证据 + 改结构 |
| 见效前提 | 被收录、被评估 | 已有排名，改完重新评估 |
| 主要风险 | 意图判断错、无人搜 | 改动过猛导致排名回落 |
| 可复用资产 | 一篇新 URL | 同一 URL 的历史权重 |
| 适合阶段 | 主题覆盖有缺口 | 已有 20 篇以上且多数在 11–30 名 |

判断标准可以写得很硬：主题覆盖还不到 15 篇、且每个模块都有明显缺口时，优先写新文；主题成型、多数词在 11–30 名之间时，把七成时间给翻新。

## 什么信号说明该翻新

| 信号 | 怎么查 | 处理 |
| :--- | :--- | :--- |
| 排名卡在第 11–30 名 | Search Console 按查询看平均排名 | 补内容深度与内链，优先 |
| 展现高、点击低 | 对比展现量与点击率 | 改标题与首段，不是改全文 |
| 内容已过期 | 版本号、价格、政策、截图 | 更新事实并加更新说明 |
| 意图漂移 | SERP 顶部页面类型变了 | 按新意图重组，或拆成两篇 |
| 内链缺口 | 没有任何支撑文链向它 | 补向上链接与矩阵 |

五个信号里，只有「排名 11–30」和「展现高点击低」是翻新能立刻改善的。

## 翻新五步，从最便宜的动作开始

1. **对照 SERP 补缺口**：看当前前十名覆盖了哪些子问题（价格、替代方案、限制、迁移），你缺哪个补哪个，而不是把全文重写。
2. **更新会过期的事实**：版本号、平台规则、截图、示例代码。所有改动集中在一个小节，避免全文散落。
3. **改标题与首段**：只压展现高点击低的那几篇；标题里保留关键词，加入读者真正在比较的差异点。
4. **补内链与转化入口**：按内链矩阵补一条向上、一条向转化页的链接，别一次加十条。
5. **留改动记录**：用一张表记下改了什么、为什么改、改前的位置，否则四周后无法归因。

改动记录可以就放在内容仓库的边上：

```csv
url,changed_on,change_type,before_rank,after_rank,note
"/zh/courses/global-site-seo/article-structure-template","2026-11-19","add-section",18,,补了对照表与骨架模板
"/zh/docs/intro","2026-11-19","rewrite-title",12,,标题加入版本号
"/zh/courses/indie-saas-launch/pain-point-inventory","2026-11-19","fix-outdated",9,,更新截图
```

## 别改完就下结论

内容改动到排名变化有一段重新评估期，通常以周计。观察窗口至少四周，按同地区、同设备、同查询集对比。

一次只改一个变量：这周只改标题，下周只补内容。

## 在本站怎么落地

正文是 `content/` 下的 MDX，改完提交即触发静态重建，sitemap 与站内搜索索引由 `scripts/build-search.mjs` 重新生成。翻新时顺手检查 frontmatter 的 `summary` 与正文首段是否仍然一致——它们会进入搜索结果摘要，最容易在翻新后被忘掉。

## 落地动作

1. 从 Search Console 导出近 90 天查询，按平均排名筛出 11–30 名、且有点击的词，取前 20 个对应到具体页面。
2. 按五步流程改其中 3 篇，每篇只做两类改动（补缺口 + 补一条内链），改动写进记录表。
3. 四周后用同一查询集对比平均排名与点击率，决定下一批继续翻新还是写新文。

## 常见坑

- **现象**：翻新了十几篇，流量没变化。→ **原因**：改的是措辞和排版，没补 SERP 上缺的子问题。→ **对策**：先列出前十名覆盖的子问题清单，只补清单里缺的项。
- **现象**：改完标题，排名掉了。→ **原因**：标题与正文意图不再匹配，或对应关键词被换掉。→ **对策**：保留原关键词，只调后半句的差异点；掉了就回滚标题、保留正文改动。
- **现象**：老文翻新后仍无起色。→ **原因**：该词 SERP 已被工具页或大站占满，内容再改也进不去。→ **对策**：把它降级为内链中转页，把资源转到同簇里更有机会的词。
