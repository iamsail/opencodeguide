「新站三个月进首页」「6 个月月流量十万」这类说法流传很广。信了它的人第三个月加大投入、第六个月停更，两次都不是因为 SEO 无效，而是用日历代替了指标。

## 新站缺的不是内容，是信任信号

搜索引擎判断一个页面能不能排，看的是可观察的信号：域名有没有被别的站链接过、有没有人直接搜它的名字、页面被点开后有没有停留、内容是否长期稳定更新。新域名这几项全是零，所以不是「算法惩罚你」，而是你还没有可比较的历史。

判定看 Search Console 三个数：已编入索引的页面数、有曝光（impressions > 0）的查询数、品牌词曝光。前两项不涨，问题在抓取与索引，加内容没用；第三项不涨，说明还没人记得你。

## 6 个月按可观察节点划，不按承诺划

| 阶段 | 你能观察到的 | 不该期待的 |
| :--- | :--- | :--- |
| 第 1 个月 | 页面被抓取，索引从 0 到几十 | 任何排名 |
| 第 2–3 个月 | 长尾词出现曝光，排名在第二三页 | 前 10 的稳定排名 |
| 第 4–5 个月 | 部分词进前 20，个别长尾进前 10 | 平滑上升的流量曲线 |
| 第 6 个月 | 3–10 个词带来持续点击 | 「月流量十万」 |

## 五种幻觉与检验方法

收录不等于排名，索引只是入场券，用 `site:` 看收录量再抽查目标词排名。内容多也不等于会排，一百篇同质文章不如十篇有独立数据的。外链带来的是风险不是速度，看外链域名与主题是否相关。AI 摘要只引用被广泛引用、结构清晰的页面，搜核心词看它引用了谁。对手做了你做也未必行，先对比双方品牌词搜索量与引用域名数。

## 用一张月报表替代感觉

```ts
// 每月填一次；两项增长缺一项就先查原因
export const health = (m: {
  indexed: number; indexedPrev: number;
  queries: number; queriesPrev: number;
  brandImpressions: number;
}) => ({
  indexing: m.indexed > m.indexedPrev,
  demand: m.queries > m.queriesPrev,
  brand: m.brandImpressions > 0,
  verdict: m.indexed > m.indexedPrev && m.queries > m.queriesPrev
    ? "继续投入" : "先修索引与内链，别加产量",
});
```

## 什么时候该止损

三种信号说明问题不在「新站」，而在方案：提交 sitemap 两周后仍有超过一半页面停在「已发现但未编入索引」，那是抓取或 canonical 的问题；所有查询的曝光都在个位数，说明词的意图与页面类型不匹配；六个月里没有一条自然外链，说明内容没被同行看过。

反过来，这三种是正常现象，别当成失败：平均排名在 40 名上下反复波动、绝大部分点击来自长尾词、品牌词曝光只有个位数。

判断止损的时点不要用「第几个月」，用「同一批页面的曝光是否在增长」。同一批页面三个月不涨，换选题或换结构都可以；每季度涨一点，说明方向对，只是慢。

## 落地动作

1. 在 Search Console 对比本月与上月，只看索引页数、有曝光查询数、品牌词曝光。
2. 把上面四个阶段抄进周报模板，每阶段写下「到点没出现时我要先查的三件事」。
3. 选 3 个目标词记录当前平均排名，之后每月同一天复测。

## 常见坑

- **现象**：6 个月后几乎没有曝光。→ **原因**：页面没被索引，或 robots、sitemap、canonical 配错。→ **对策**：先看「已发现但未编入索引」，逐页查 canonical、robots 与站内链接。
- **现象**：写得越多，平均排名越低。→ **原因**：批量生产同质页面，拉低整站质量，也分散了内链。→ **对策**：停止扩量，合并重复页，内链集中到 10 个核心页。
- **现象**：三个月没起色就换方向，一年换四个站。→ **原因**：用日历而不是指标判断进度。→ **对策**：以三项指标作为唯一进度口径。
