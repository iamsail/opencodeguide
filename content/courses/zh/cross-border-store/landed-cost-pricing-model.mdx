用采购价乘一个倍数来定价，月底发现账上没有钱，是跨境独立站最普遍的账。原因通常不是卖得便宜，而是漏算了三样：头程与关税、退货损耗、以及把广告费当成固定开支而不是每一单的变动成本。

## 到岸成本：采购价之外的六项

采购单价、头程（含保险）、关税与进口环节税、清关与报关代理费、仓储与入仓分摊、尾程。这几项都要摊到单件：

`单件到岸成本 = (采购 + 头程 + 关税 + 清关) ÷ 单批数量 + 单件尾程 + 单件包装`

两个容易漏的地方。一是数量分摊：一批货里次品与损耗要算进分母，否则单件成本被低估。二是尾程不是固定值，重量、体积重、偏远地区附加费都会拉高它，报价要用「最坏情况的一档」而不是最低档。

## 关税怎么估，且不要写死税率

按 HS 编码到目的地海关税则里查，或直接问货代要「到手含税价」，后者更省事也更接近真实。

要点有三条。归类责任在你，编码归错会被追缴并可能罚款；申报价影响税额，低报属于违法，不是「节省成本」；DDP 与 DDU 决定税额在结账时收还是在收货时收，后者会显著压低转化率。具体税率随编码、原产地、贸易协定与申报时点变化，任何一口价都不可靠，所以模型里留一个可替换的字段，按批次更新。

## 广告费是变动成本，不是固定开支

因为它是按订单发生的。两个定义必须写清：

`获客成本 = 广告花费 ÷ 成交订单数`

`盈亏平衡 ROAS = 售价 ÷ 单件毛利（不含广告）`

分母要用成交订单数，不要用点击或加购；退货订单要从成交里扣掉，否则 ROAS 虚高，越投越亏还看不出来。实际 ROAS 低于盈亏平衡值时，每一单都在放大亏损。

## 一张表算出最低售价

| 项目 | 计算方式 | 占售价比 |
| :--- | :--- | :--- |
| 售价 P | 决策变量 | 100% |
| 采购 + 头程 + 关税 + 包装 | 按批次摊到单件，固定金额 | 固定项 |
| 尾程 | 按最坏一档取固定金额 | 固定项 |
| 支付手续费 | P × 服务商费率（以价目表为准） | 变动比例 |
| 退货损耗 | P × 退货率 × 单笔不可回收损失比例 | 变动比例 |
| 广告费 | 由投放决定，需满足 ROAS ≥ 售价 ÷ 毛利 | 变动比例 |
| 建站与工具 | 月固定成本 ÷ 月订单数 | 固定项 |

反算最低售价：

`P_min = 固定项合计 ÷ (1 − 变动项占售价比例之和 − 目标毛利率)`

算出来的 P_min 高于竞品售价，说明这个供应商报价在当前物流与退货结构下做不了，要么换货源，要么改包装降体积重，要么放弃。

```ts
type SkuInput = {
  price: number;         // 售价（DDP，税费已含）
  goods: number;         // 采购单价
  freightIn: number;     // 头程分摊到单件
  duty: number;          // 关税与进口环节税，按货代含税到手价反推
  lastMile: number;      // 尾程
  packaging: number;     // 包装与耗材
  paymentRate: number;   // 支付费率，占售价比，以服务商价目表为准
  refundRate: number;    // 退货率
  refundLoss: number;    // 单笔退货不可回收损失，占售价比
  fixedMonthly: number;  // 每月固定成本
};

export function unitMargin(i: SkuInput) {
  const variable =
    i.goods + i.freightIn + i.duty + i.lastMile + i.packaging +
    i.price * i.paymentRate +
    i.price * i.refundRate * i.refundLoss;

  const margin = i.price - variable;      // 单件毛利，不含广告
  return {
    margin,
    marginRate: margin / i.price,
    breakevenRoas: i.price / margin,      // 广告花费 ÷ 成交额 的上限
    minOrdersPerMonth: Math.ceil(i.fixedMonthly / margin),
  };
}
```

参数全部从自己的账单里取值，不用行业平均数。填完先跑一遍现有 SKU，看是否与最近的银行流水对得上，对不上说明漏项。

## 落地动作

1. 拿最近一个月卖得最好的三个 SKU，把表填满，缺的项标「未知」而不是猜。
2. 向货代要这三个 SKU 的「含税到手价」，用它替换模型里的关税字段并对比差异。
3. 把每个 SKU 的盈亏平衡 ROAS 写进投放账户的备注与素材测试门槛，低于它的广告组当天停。

## 常见坑

- **现象**：广告 ROAS 看着达标，月底没有利润。→ **原因**：退货与拒付没从成交里扣，尾程涨价与支付费率变更后模型没更新。→ **对策**：模型里单列退货损耗，尾程与费率按季度回填一次实际值。
- **现象**：结账页很顺，收货时被追缴关税，投诉与拒付集中出现。→ **原因**：用了 DDU，税费被推到收货环节，用户在结账时看到的价不是最终价。→ **对策**：改 DDP 并把关税计入售价，或在结账页明确标注税费另计。
- **现象**：为了价格竞争力压低申报价，被海关追缴加罚。→ **原因**：把低报当成常规成本优化手段，风险被当成概率问题忽略。→ **对策**：用货代给的含税到手价建模，把合规成本当成必付项而不是可调项。
