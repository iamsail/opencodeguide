供应商回一句「我们有 CE」，是跨境采购里最贵的一句话。CE 不是一个可以复印的标志，而是一套要由欧盟境内责任主体兜住的技术文件；FCC 对无线发射设备与非无线设备走的路径不同；电池和化妆品根本不在这套逻辑里，各有独立的法规体系。你要买的是「能清关、能上架、出事能自证」，不是箱子上那个图案。

## 认证是文件包，不是标志

| 品类 | 核心要求 | 谁承担 | 要拿到的文件 |
| :--- | :--- | :--- | :--- |
| 一般电子（安规、电磁兼容） | 符合性声明 + 技术文件 | 欧盟境内责任主体 | 声明、测试报告、技术文件清单 |
| 无线设备 | 无线电设备法规；美国另有 FCC 路径 | 制造商或进口商 | 射频测试报告、FCC 标识或自我声明记录 |
| 含锂电池产品 | 电池法规与运输测试 | 发货人或进口商 | 电池测试报告、运输鉴定、安全数据表 |
| 化妆品 | 欧盟责任人、产品信息文件、上市通报 | 责任人 | 安全评估报告、通报记录、成分标签 |

三份文件各解决一个问题：测试报告回答「测过」，符合性声明回答「声明符合哪些法规」，技术文件回答「凭什么这么说」。只拿到第一份就开始卖，是最常见的状态——报告是真的，但缺声明，或声明里的型号与在售型号对不上。抽查看的是三者能否互相印证，不是单看某一页盖章。

审核方真正核对的三点：型号是否一致、标准版本是否仍有效、文件是否覆盖你实际销售的变体。变体这条杀伤力最大：换了大容量电池或换了电源适配器，就可能构成新型号。供应商说「一样的，不用改」，通常指外观一样。

## 责任落在谁头上，决定要不要有主体

三个角色要分清：制造商（设计生产的）、进口商（把货带进市场的）、平台（只负责审核与下架）。非欧盟卖家直邮卖货时，往往自己就是进口商；没有境内责任主体，测试再齐全也可能在抽查时被判不合规。

平台抽查给的处理窗口很短，给不出文件的结果是链接下架、库存冻结。这是「不注册主体」这条省钱路线最实在的代价：不是罚款，是货卡在仓库里。

## 成本要按摊销算，不是按绝对值算

`单件摊销 = 认证与测试总成本 ÷ 该型号预计销量`

摊销接近单件毛利，说明这个品类要靠规模才能消化合规成本，小批量测款不成立。更直接的判断是回本销量：

`回本销量 = 认证总成本 ÷ 单件毛利`

算出这个数，再看渠道能不能在可接受时间内卖完。算不出来，就先别付测试费，先换品。

## 什么时候可以先不做

只卖非电子、非化妆品、非儿童用品，且平台类目本身不要求资质时，可以先不投入。用小批量直邮测款也能延后，但要接受两个风险：清关被要求补文件、平台审核直接下架链接。

反过来，客单价高、复购稳定、准备进本地仓的品类，认证是入场成本而非可选项——没有它，货都进不去。

## 向供应商索取的清单

```yaml
# docs/supplier-compliance.yaml —— 每个 SKU 一份，缺项标红再上架
sku: "SKU-001"
category: electronics_with_battery
documents:
  - name: 测试报告
    issuer: 第三方实验室          # 要能查到实验室资质
    must_match: [型号, 关键元件, 电池容量]
    received: false
  - name: 符合性声明
    issuer: 制造商                # 需签字盖章，含法规清单
    must_match: [型号, 制造商地址]
    received: false
  - name: 技术文件清单
    issuer: 制造商
    must_match: [风险评估, 元件清单]
    received: false
  - name: 运输测试与安全数据表
    issuer: 电池供应商或实验室
    must_match: [电池型号, 瓦时数]
    received: false
owner: "欧盟授权代表（如适用）"
reviewed_at: null
```

这份文件的作用不是存档，而是把「还缺哪一份」变成看得见的状态。缺项不标出来，采购会一直以为已经齐了。

## 落地动作

1. 给每个在售 SKU 建一份上面的清单，先填「已知有的」，空着的就是风险。
2. 拿型号去核对报告与声明是否一致，不一致的退回供应商，不要自己改。
3. 确认自己在该市场是否需要责任主体；需要就先解决角色，再谈测试。
4. 新品用回本销量公式做判断，算不出可接受销量就换品，别先付测试费。

## 常见坑

- **现象**：供应商发来一张证书照片，看着像 CE → **原因**：那可能是自我声明格式文件，或别的型号的证书 → **对策**：核对型号、标准版本与签发机构，要求提供完整技术文件。
- **现象**：换了电池供应商，链接被下架 → **原因**：关键元件变更通常构成新型号，原测试不再覆盖 → **对策**：把关键元件纳入变更管理，任何替换都重新确认合规。
- **现象**：产品在美国被限制销售 → **原因**：把 CE 当全球通用，忽略美国对无线设备的独立要求 → **对策**：按目标市场分别立项，别用一个市场的文件覆盖另一个。
