问「海运一公斤多少钱」的人，通常会在三个月后发现吃掉利润的不是海运费，而是那批货在仓库里躺着的第九十天。履约成本是一组随时间变化的费用，不是一张报价单。

## 报价单只覆盖了其中一段

头程按批次收费，计费重取实重与体积重里较大的那个；入库和上架按件收；仓储按月按体积收，超期部分单价会上跳；尾程按单收，且按分区计价；退回来的货再走一遍入库、检测、上架。这五段的驱动变量完全不同：头程看体积，仓储看周转，尾程看单量与目的地，退货看品类。

压成一个「每公斤多少钱」横向比较，结论必然是错的。要比的是同一件货、同一段时间里五段费用加总后的单件成本。

## 三种模式的差别在成本结构，不在总价

直发的边际成本是常数：卖一件付一件，不压库存，但单件成本高、时效长、退货无解。海外仓把固定成本前置，单件随批量下降，代价是库存与预测。

| 维度 | 直发小包 / 专线 | 海外仓 | 混合 |
| :--- | :--- | :--- | :--- |
| 成本形态 | 全变动，随单量线性 | 固定前置 + 变动尾程 | 爆款固定，长尾变动 |
| 现金占用 | 几乎为零 | 在途 + 在库货值 | 只占爆款 |
| 时效可控性 | 清关段不可控 | 可控，尾程按当地网络 | 分类可控 |
| 退货可行性 | 几乎不可行 | 可本地处理并二次销售 | 部分可行 |
| 起量门槛 | 无 | 有，按 SKU 计 | 低 |
| 主要风险 | 单件成本与体验 | 滞销与断货同时存在 | 两套流程都要维护 |

## 用两道检查代替「哪个便宜」

第一道看单件成本，决定模式是否成立；第二道看固定费用摊薄，决定现在是否够量。两道都过才值得备货。

```ts
// 检查一：单件落地前的履约成本（不含关税与税费，那部分单独算）
function unitCost(p: {
  firstLegPerBatch: number;   // 整批头程费用，含清关与拖车
  batchUnits: number;         // 该批次件数
  inboundPerUnit: number;     // 入库、上架、贴标
  storagePerUnitMonth: number;
  turnoverMonths: number;     // 平均在库月数 = 周转天数 / 30
  lastMile: number;           // 尾程单价（按分区取加权值）
  returnRate: number;
  returnCostPerOrder: number; // 单次退货的往返与检测成本
  directPerOrder: number;     // 直发每单运费
}) {
  const returns = p.returnRate * p.returnCostPerOrder;
  const overseas =
    p.firstLegPerBatch / p.batchUnits +
    p.inboundPerUnit +
    p.storagePerUnitMonth * p.turnoverMonths +
    p.lastMile +
    returns;
  return { direct: p.directPerOrder + returns, overseas };
}

// 检查二：月固定费用（仓储最低消费、系统费、退货地址服务费）需要多少单才摊平
function breakEvenOrders(monthlyFixed: number, directPerOrder: number, overseasVariable: number) {
  const saving = directPerOrder - overseasVariable;
  return saving > 0 ? Math.ceil(monthlyFixed / saving) : Number.POSITIVE_INFINITY;
}
```

还有一项常被漏掉：滞销计提。周转从两个月拖到四个月，仓储费翻倍只是小头，真正的损失是季末折价清货。规则是「在库超过预设周转期的 SKU 按折价率计提」，把它加进单件成本，海外仓的账面优势通常会缩水。

## 头程的计费方式会反过来改你的包装

计费重取实重与体积重的较大值，泡货按体积付费，系数由承运商定。这意味着改包装同时降头程与按体积计的仓储。

但要守住破损率：省下的运费抵不过一次破损退货的往返加退款，含电池或易碎品类更是如此。改包装后先小批量试点看破损与客诉，再全量替换。

## 小团队的最小可行版本

先用直发跑足够长的时间，拿到真实的分区重量分布与退货率，再决定备哪几个 SKU。只给一到两个爆款备货，其余直发，这就是混合模式的最小形态。

什么时候可以不做：SKU 极多且单个销量低、产品迭代快（备货即过时）、客单价低到仓储与操作费占比过高、差异化本来就在定制与长尾。这几种情况下，投在选品与转化率上比压尾程单价回报更高。

## 落地动作

1. 拉出过去一个月的订单，按目的地分区和计费重分档，算出直发的加权单件运费，别用报价单首重价。
2. 挑一个候选 SKU，向两家海外仓要按件、按月、按体积列明的价目，填进上面的 `unitCost`；缺的项标为未知，不要猜。
3. 用 `breakEvenOrders` 算出摊平月固定费用所需的单量，与该 SKU 当前月销对比，写下差多少单。
4. 把结论写成一行决策记录：模式、盈亏平衡单量、复核时间点、触发切换的条件。

## 常见坑

- **现象**：海外仓单件成本算下来比直发便宜三成，实际毛利反而下降 → **原因**：只算了变动费用，没算月固定费用、滞销计提与周转变慢占用的现金 → **对策**：把两道检查都跑一遍，固定费用按当前真实单量摊，不要按规划单量摊。
- **现象**：头程报价比同行高，换了一家便宜的结果总成本更高 → **原因**：只比每公斤单价，没比计费重口径与清关杂费 → **对策**：要求报价单按「整批到手总价」列明，并注明计费重系数与杂费项。
- **现象**：备货后旺季断货、淡季压货，两头都亏 → **原因**：按一次性预测定批次，没有补货触发线 → **对策**：给每个 SKU 设补货点（在库量低于安全库存即触发），按周复核，而不是按季度重新预测。
