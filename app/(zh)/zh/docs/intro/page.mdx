OpenCode 是一款开源 AI 编码智能体（agent）。你可以通过终端界面、桌面应用或 Web 应用使用它。


## CLI

<CodeTabs id="install" label="Install method" tabs='[{"label":"curl","code":"curl -fsSL https://opencode.ai/v2/install | bash"},{"label":"homebrew","code":"brew install anomalyco/tap/opencode-v2"},{"label":"npm","code":"npm install -g @opencode/cli"},{"label":"bun","code":"bun install -g --trust @opencode/cli"},{"label":"pnpm","code":"pnpm add -g --allow-build=@opencode/cli @opencode/cli"},{"label":"yarn","code":"yarn global add @opencode/cli"},{"label":"vite+","code":"vp install -g @opencode/cli"},{"label":"aur","code":"paru -S opencode-beta"},{"label":"mise","code":"mise use -g opencode"}]' />

npm 包会通过 postinstall 脚本为你所用的平台选择对应的原生 `opencode` 二进制文件。Bun 与 pnpm 命令显式允许运行该必需脚本；Vite+ 无需附加标志。mise 命令需要 mise 2026.10.9 或更高版本；较早版本会安装 OpenCode 1。

不支持 Windows 包管理器。


下载适用于你平台的独立 CLI 二进制文件。

- **macOS:** [Apple 芯片](https://opencode.ai/update/api/latest/cli/opencode/opencode-darwin-arm64.zip) · [Intel](https://opencode.ai/update/api/latest/cli/opencode/opencode-darwin-x64.zip) · [Intel (基线版)](https://opencode.ai/update/api/latest/cli/opencode/opencode-darwin-x64-baseline.zip)
- **Windows:** [ARM64](https://opencode.ai/update/api/latest/cli/opencode/opencode-windows-arm64.zip) · [x64](https://opencode.ai/update/api/latest/cli/opencode/opencode-windows-x64.zip) · [x64 (基线版)](https://opencode.ai/update/api/latest/cli/opencode/opencode-windows-x64-baseline.zip)
- **Linux (glibc):** [ARM64](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-arm64.tar.gz) · [x64](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-x64.tar.gz) · [x64 (基线版)](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-x64-baseline.tar.gz)
- **Linux (musl):** [ARM64](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-arm64-musl.tar.gz) · [x64](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-x64-musl.tar.gz) · [x64 (基线版)](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-x64-baseline-musl.tar.gz)

## 网页版

使用 `opencode pair` 命令访问 OpenCode 网页界面。

```bash
$ opencode pair

  Open a link to connect. Links work once and expire in 5 minutes.

  http://127.0.0.1:49374/auth/connect/...
```

## Docker

Docker 镜像使用带版本号的标签，例如 `ghcr.io/anomalyco/opencode:2.0.0`。

---

## 连接

OpenCode 内置支持众多 LLM 提供商。你可以直接[在 TUI 中](/zh/docs/cli/providers)使用 `/connect` 进行连接。

参见[提供商](/zh/docs/providers)以配置自定义提供商。

如果你想便捷地使用所有最佳编码模型，可以试试 [OpenCode Console](/zh/docs/console)。

你也可以试试 [OpenCode Go](/zh/docs/console/go)——一项每月 $10 的订阅计划，可让你使用最佳编码模型。

---

## 自定义

你可以通过编辑 [OpenCode 配置](/zh/docs/config)、[加载插件](/zh/docs/configure/plugins)、[连接 MCP 服务器](/zh/docs/configure/mcp-servers)或[创建命令](/zh/docs/configure/commands)来打造专属你的 OpenCode。有关终端界面的主题与快捷键，请参阅 [CLI 设置](/zh/docs/cli/config)。
