在项目目录中运行 OpenCode，输入请求，然后按 **Enter**。

```bash
cd ~/code/my-project
opencode
```

```text
Explain how authentication works in this project
```

按 **Shift+Enter**、**Ctrl+Enter**、**Alt+Enter** 或 **Ctrl+J** 可换行。OpenCode 工作期间，按 **Enter** 可引导当前会话；按 **Ctrl+X** 再按 **Enter** 可将提示排队留待稍后执行。

## 上下文

输入 `@` 可搜索文件，选中后即可将该文件附加到提示中。在 `@` 后继续输入可缩小结果范围。

```text
Review @src/auth.ts for error handling problems
```

可以在路径后附加行号或行号范围。

```text
Explain @src/auth.ts#20-45
```

## Shell

在空白提示开头输入 `!` 可进入 shell 模式。输入命令后按 **Enter** 执行；按 **Esc** 可退出 shell 模式而不执行命令。

```text
!git status
```

shell 命令在会话的工作目录中运行，其输出会保留在会话中。

## 命令

输入 `/` 可列出斜杠命令。继续输入可筛选列表，然后按 **Enter** 运行所选命令。

```text
/models
```

常用命令包括 `/new`、`/sessions`、`/models`、`/agents`、`/undo`、`/redo` 和 `/editor`。按 **Ctrl+P** 可打开命令面板，其中包含当前视图中所有可用的操作。

更新后，OpenCode 会在主屏幕上一次性展示该版本的新特性。运行 `/highlights` 可再次查看；在 [`cli.json`](/zh/docs/cli/config#alerts) 中设置 `"highlights": false` 可阻止其自动打开。

## 顺带提问

运行 `/btw <question>` 可就当前对话提出一个快速问题。回答会使用会话的上下文与当前模型，但不会写入对话，因此不会影响后续提示。运行期间提示框底部会显示 `/btw` 指示器，回答在对话框中打开；按 **C** 可复制。

```text
/btw why did the test in step 2 fail?
```

## 模型

按 **Ctrl+X** 再按 **M** 可选择模型，或运行 `/models`。按 **F2** 可在最近使用的模型之间循环切换。

按 **Ctrl+X** 再按 **A** 可选择智能体，或运行 `/agents`。按 **Shift+Tab** 可循环切换智能体。

## 会话

按 **Ctrl+X** 再按 **N** 可开始新会话。按 **Ctrl+X** 再按 **L**，或运行 `/sessions`，可返回已有会话；**Ctrl+O** 可同时打开最近的会话与项目。

标签页默认启用。使用 **Ctrl+Tab** 和 **Ctrl+Shift+Tab** 在标签页之间切换，按 **Ctrl+X** 再按 **W** 关闭当前标签页，按 **Ctrl+Shift+T** 重新打开最近关闭的标签页。

## 历史

按 **Ctrl+X** 再按 **U**，或运行 `/undo`，可撤销最近一条用户消息及其后续工作。被撤销的提示会回到输入框，供你编辑。

按 **Ctrl+X** 再按 **R**，或运行 `/redo`，可恢复被撤销的工作。若改为发送新提示，则表示接受此次撤销，并从该位置继续。

## 编辑器

设置 `VISUAL` 或 `EDITOR` 后，按 **Ctrl+X** 再按 **E**，或运行 `/editor`，即可在该编辑器中编辑当前提示。保存并退出后文本会回到输入框，再按 **Enter** 发送。

```bash
export EDITOR="nvim"
opencode
```

默认的前导键（leader key）是 **Ctrl+X**。参见[快捷键](/zh/docs/configure/keybinds)了解如何修改这些快捷键。
