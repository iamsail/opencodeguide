OpenCode 可以在其 `write`、`edit` 或 `patch` 工具修改文件后对其进行格式化。格式化工具默认处于禁用状态，因此需要在配置中启用：

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "formatter": true,
}
```

## 启用

将 `formatter` 设为 `true` 可启用全部内置格式化工具。只有在相应可执行文件及项目特定要求均满足时，OpenCode 才会运行该内置工具。

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "formatter": true,
}
```

传入对象同样会启用内置工具，并允许你覆盖它们或添加自定义格式化工具。空对象会保留继承的格式化工具设置，而 `true` 则会将它们重置为内置默认值。

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "formatter": {},
}
```

## 内置工具

| `gofmt` | `.go` | `gofmt` 命令 |

```jsonc title="opencode.jsonc"
{
  "formatter": true,
}
```

## 自定义

添加一个具名条目即可修改内置工具或定义自定义格式化工具。自定义格式化工具必须同时提供 `command` 和 `extensions` 才能运行。

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "formatter": {
    "prettier": {
      "environment": {
        "NODE_ENV": "development",
      },
      "extensions": [".js", ".ts"],
    },
    "deno-markdown": {
      "command": ["deno", "fmt", "$FILE"],
      "extensions": [".md"],
    },
  },
}
```

| 字段 | 类型 | 行为 |
| --- | --- | --- |
| `disabled` | `boolean` | 为 `true` 时移除该具名格式化工具。 |
| `command` | `string[]` | 替换内置命令或定义自定义命令。 |
| `environment` | `Record<string, string>` | 添加环境变量，同时保留父级环境。 |
| `extensions` | `string[]` | 替换内置扩展名列表或定义自定义列表。需包含前导点号。 |

所有字段均为可选。内置条目会继承省略的值，而缺少 `command` 或 `extensions` 的新条目无法运行。

```jsonc title="opencode.jsonc"
{
  "formatter": {
    "prettier": {
      "extensions": [".md", ".mdx"],
    },
  },
}
```

## 命令

`command` 是参数数组，而不是 shell 命令字符串。OpenCode 会将 `$FILE` 替换为文件的绝对路径，并在活动项目目录中运行该命令。

```jsonc title="opencode.jsonc"
{
  "formatter": {
    "custom": {
      "command": ["custom-fmt", "--write", "$FILE"],
      "extensions": [".custom"],
    },
  },
}
```

## 匹配规则

OpenCode 会将文件的最终扩展名与 `extensions` 进行比较。匹配区分大小写，且像 `.part.md` 这样的复合条目不会匹配 `notes.part.md`，因为后者的最终扩展名是 `.md`。

```jsonc title="opencode.jsonc"
{
  "formatter": {
    "markdown": {
      "command": ["deno", "fmt", "$FILE"],
      "extensions": [".md"],
    },
  },
}
```

当有多个格式化工具匹配时，OpenCode 会按注册顺序依次尝试，并在首个命令成功后停止。内置工具保持其内置顺序；自定义条目则按对象顺序紧随其后。如果某个命令以失败退出，OpenCode 会记录该失败并尝试下一个匹配项。

```jsonc title="opencode.jsonc"
{
  "formatter": {
    "preferred": {
      "command": ["preferred-fmt", "$FILE"],
      "extensions": [".foo"],
    },
    "fallback": {
      "command": ["fallback-fmt", "$FILE"],
      "extensions": [".foo"],
    },
  },
}
```

## 禁用

当没有配置文件设置 `formatter` 时，格式化处于禁用状态。若要禁用被较低优先级文件启用的格式化功能，可将其设为 `false`。

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "formatter": false,
}
```

若要在保持其他工具启用的同时禁用某个内置工具，可将其具名条目标记为已禁用。

```jsonc title="opencode.jsonc"
{
  "formatter": {
    "prettier": {
      "disabled": true,
    },
  },
}
