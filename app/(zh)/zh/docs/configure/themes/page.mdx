在终端界面中按 `Ctrl+P`，选择 **Open settings**，再打开 **Theme** 即可选择主题。也可以在全局 CLI 配置中直接设置：

```json title="~/.config/opencode/cli.json"
{
  "theme": {
    "name": "tokyonight",
    "mode": "system"
  }
}
```

主题属于终端客户端。请将主题选择写在 `cli.json` 中，而不是 `opencode.json`。配置位置及其他终端设置请参阅 [CLI 设置](/zh/docs/cli/config)。

## 模式

使用 `system` 可跟随终端的外观，也可以将主题锁定为某一模式：

```json title="~/.config/opencode/cli.json"
{
  "theme": {
    "name": "opencode",
    "mode": "dark"
  }
}
```

| 值 | 行为 |
| -------- | --------------------------------------------- |
| `system` | 跟随终端的浅色或深色模式。 |
| `dark` | 始终使用深色主题。 |
| `light` | 始终使用浅色主题。 |

如果自定义主题只提供一种模式，则当请求另一种模式时，OpenCode 会使用该模式。

## 内置主题

按名称选择内置主题：

```json title="~/.config/opencode/cli.json"
{
  "theme": {
    "name": "catppuccin"
  }
}
```

可用主题包括：

- `aura`, `ayu`, `carbonfox`, `cobalt2`, `cursor`, `dracula`, `everforest`, `flexoki`
- `catppuccin`, `catppuccin-frappe`, `catppuccin-macchiato`
- `github`, `gruvbox`, `kanagawa`, `material`, `matrix`, `mercury`, `monokai`, `nightowl`, `nord`
- `one-dark`, `opencode`, `orng`, `lucent-orng`, `osaka-jade`, `palenight`, `rosepine`
- `solarized`, `synthwave84`, `tokyonight`, `vercel`, `vesper`, `zenburn`

当 OpenCode 能够读取终端调色板时，`system` 主题可用。

## 文件

要创建名为 `ocean` 的全局主题，请使用主题工具在全局主题目录中生成完整文件。其相关结构如下：

```json title="~/.config/opencode/themes/ocean.json (excerpt)"
{
  "base": {
    "text": {
      "base": "#d8f3ff"
    }
  },
  "dark": {
    "hue": {
      "accent": "$hue.cyan"
    }
  }
}
```

然后在设置中选择 `ocean`，或在 `cli.json` 中将 `theme.name` 设为 `ocean`。去掉 `.json` 后的文件名即主题名。

| 范围 | 目录 |
| ------- | ------------------------------------------ |
| 全局 | `~/.config/opencode/themes/` |
| 项目 | 项目树中的 `.opencode/themes/` |

OpenCode 只读取 `.json` 文件。更靠近当前目录的主题会替换同名的全局或父级主题。

## 格式

每个 V2 主题都会声明一棵完整的 `base` 令牌树，以及至少一个 `light` 或 `dark` 色相调色板。各模式仅继承该文件中的 base，不继承内置的 OpenCode 主题，也不互相继承。在自定义之前，请先使用主题工具生成完整的 base。

下面的示例仅展示与各概念相关的部分，并非完整主题文件。

```json title="themes/ocean.json"
{
  "base": {
    "text": {
      "base": "#16324f"
    }
  },
  "light": {
    "hue": {}
  },
  "dark": {
    "hue": {},
    "text": { "base": "#d8f3ff" }
  }
}
```

## 颜色

使用十六进制颜色、`transparent`，或对其他主题颜色的引用：

```json title="themes/ocean.json"
{
  "base": {
    "text": {
      "base": "#d8f3ff",
      "muted": "$hue.neutral.400"
    },
    "background": {
      "base": "transparent"
    }
  }
}
```

十六进制值可使用 3、4、6 或 8 位数字。引用以 `$` 开头；色相引用采用 `$hue.<name>.<step>` 形式。

## 色相

覆写色相别名，可一次更改一族相关颜色：

```json title="themes/ocean.json"
{
  "base": {
    "categorical": ["accent", "purple", "green"]
  },
  "dark": {
    "hue": {
      "accent": "$hue.cyan",
      "interactive": "$hue.blue"
    }
  }
}
```

| 类型 | 值 |
| ------- | -------------------------------------------------------------------- |
| 基色 | `gray`, `red`, `orange`, `yellow`, `green`, `cyan`, `blue`, `purple` |
| 别名 | `accent`, `interactive`, `neutral` |
| 色阶 | `100`, `200`, `300`, `400`, `500`, `600`, `700`, `800`, `900` |

色阶遵循该模式的对比度方向：浅色主题从 `100` 的深色过渡到 `900` 的浅色，而深色主题从 `100` 的浅色过渡到 `900` 的深色。

`categorical` 设置用于区分智能体及其他重复项的有序色相。它必须至少包含一个基色或别名。

## 状态

使用状态键可更改交互颜色。未指定的状态会使用最接近的基值：

```json title="themes/ocean.json"
{
  "base": {
    "text": {
      "action": {
        "primary": {
          "base": "$hue.interactive.400",
          "$hovered": "$hue.interactive.300",
          "$disabled": "$hue.neutral.600"
        }
      }
    }
  }
}
```

| 分组 | 值 |
| --------- | --------------------------------------------------------- |
| 操作 | `primary`, `secondary`, `destructive` |
| 状态 | `$hovered`, `$focused`, `$pressed`, `$selected`, `$disabled` |

表单字段直接在 `text.formfield` 或 `background.formfield` 下使用相同的状态键。

## 令牌

完整的 `base` 包含所有令牌组。某个模式在提供其完整色相调色板后，可覆写其中的任意部分：

```json title="themes/ocean.json"
{
  "base": {
    "border": {
      "base": "$hue.neutral.700"
    },
    "syntax": {
      "comment": "$hue.neutral.500",
      "keyword": "$hue.accent.400"
    },
    "diff": {
      "text": {
        "added": "$hue.green.400",
        "removed": "$hue.red.400"
      }
    }
  }
}
```

| 组 | 用途 |
| ------------ | ------------------------------------------------------------- |
| `text` | 基础、弱化、微弱、操作、表单字段及反馈文本 |
| `background` | 基础、表面、操作、表单字段及反馈填充 |
| `border` | 边框 |
| `scrollbar` | 滚动条 |
| `diff` | 新增、删除、上下文、高亮及行号颜色 |
| `syntax` | 源代码高亮 |
| `markdown` | Markdown 元素 |

语法键为 `comment`、`keyword`、`function`、`variable`、`string`、`number`、`type`、`operator` 和 `punctuation`。Markdown 键为 `text`、`heading`、`link`、`linkText`、`code`、`blockQuote`、`emphasis`、`strong`、`horizontalRule`、`listItem`、`listEnumeration`、`image`、`imageText` 和 `codeBlock`。

## 抬升表面

面板、对话框、菜单和 toast 会从 `background.raised` 中选择其深度。对话框还额外支持上下文相关的 `@dialog` 表面。TUI 在应用 `@dialog` 后会重新解析调色板，因此引用 `$background.base` 的令牌会跟随对话框背景：

```json title="themes/ocean.json"
{
  "base": {
    "background": {
      "base": "#071521",
      "raised": {
        "base": "#0c1f2e",
        "high": "#102a3c",
        "max": "#16364b"
      }
    },
    "@dialog": {
      "background": {
        "base": "$background.raised.base"
      }
    }
  }
}
```

`@dialog` 接受与 base 模式相同的令牌组。操作的上下文 `base` 也会成为其未指定状态的回退值；显式的状态覆写仍然优先。
