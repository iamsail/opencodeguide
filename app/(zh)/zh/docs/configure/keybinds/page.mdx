在 `cli.json` 中自定义绑定：

```json title="cli.json"
{
  "keybinds": {
    "leader": "ctrl+space",
    "command.palette.show": "ctrl+k",
    "app.exit": ["ctrl+c", "ctrl+d"],
    "app.debug": false
  },
  "leader": {
    "timeout": 1500
  }
}
```

单个按键使用字符串：

```json
{
  "keybinds": {
    "command.palette.show": "ctrl+k"
  }
}
```

多个备选按键用逗号分隔：

```json
{
  "keybinds": {
    "app.exit": "ctrl+c,ctrl+d"
  }
}
```

使用 `"none"` 或 `false` 禁用绑定：

```json
{
  "keybinds": {
    "app.debug": "none",
    "help.show": false
  }
}
```

使用对象配置事件行为：

```json
{
  "keybinds": {
    "prompt.paste": {
      "key": "ctrl+v",
      "preventDefault": false
    }
  }
}
```

`leader` 默认为 `ctrl+x`。其他绑定中的 `<leader>` 指代该按键。

```json
{
  "keybinds": {
    "leader": "ctrl+space",
    "model.list": "<leader>m"
  },
  "leader": {
    "timeout": 2000
  }
}
```

未知的命令 ID 会被忽略。

## Mini

## Diff 查看器

按 `d`（`diff.switch_source`）可选择 **全部**、**已提交**、**未提交** 或 **上一轮**（在会话内），或选择 **基准** 以更改比较分支。所选范围会一直保留到 TUI 退出。可通过 [`cli.json` 中的 `diffs.source`](/zh/docs/cli/config#diffs) 设置初始范围。

滚动、翻页与跳转到开头/结尾的快捷键始终控制 diff。没有键盘焦点切换：点击文件可打开，点击文件夹可展开或折叠，使用鼠标滚轮滚动文件树。

使用 `n` / `p` 或 `alt+down` / `alt+up`（macOS 上为 Option）在文件之间移动。在 diff 查看器内，Alt 快捷键用于在文件间导航，而非切换会话标签页。

按 `m` 可将文件标记为已审阅并折叠其补丁内容。在全部文件视图中，再次按 `m` 可取消标记并重新展开补丁。单文件视图在标记为已审阅时会自动前进到下一个文件，但到达最后一个文件时会停留而不会循环。取消标记文件时不会前进。

在侧边栏中右键点击文件，或右键点击其 diff 标题，可选择 **标记完成**（或 **标记未完成**）。这与 `m` 修改的是同一审阅状态。通过菜单完成另一个文件时，既不会选中该文件，也不会影响当前正在阅读的文件的进度。

带 Shift 的 `diff.help` 备选按键用于支持在按下 `?` 时报告 Shift 修饰键的终端。
