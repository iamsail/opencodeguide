在项目目录中运行 CLI 以打开全屏终端界面：

```bash
opencode
```

传入目录路径即可在其他项目中工作：

```bash
opencode ~/code/my-project
```

推荐终端：

- [Ghostty](https://ghostty.org)
- [WezTerm](https://wezterm.org)
- [Alacritty](https://alacritty.org)
- [Kitty](https://sw.kovidgoyal.net/kitty/)

真彩色支持能让主题呈现最准确的色彩；不支持的终端则使用可用调色板的近似值。

## 自动化

使用 `opencode run` 提交提示词，无需打开交互式界面。它专为脚本、CI 任务，以及其他需要直接在终端获取模型输出的工作流而设计。

```bash
opencode run "Explain this repository"
```

## Mini

使用 `opencode mini` 启动 OpenCode 的极简交互界面，而非全屏 TUI。

```bash
opencode mini
```

运行 `opencode mini --help` 可查看其会话、模型、智能体、提示词与回放选项。

## 后台服务

默认情况下，OpenCode 会为你的用户账号发现或启动一个共享后台服务器。每个本地 OpenCode 客户端都会连接到该服务器；会话、配置、集成、权限与工具执行均由该服务器负责。

使用 `--standalone` 以私有服务器运行，或使用 `--server` 连接到指定的服务器 URL：

```bash
opencode --standalone
opencode --server http://localhost:4096
```

若希望 CLI 命令默认使用私有服务器而非启动共享服务，可将其禁用：

```bash
opencode service set disabled true
opencode
```

此操作会停止正在运行的后台服务。`--server` 仍可连接到明确指定的服务器；`opencode service start` 仍可显式启动共享服务。若要恢复自动使用服务，请运行 `opencode service unset disabled`。配对依赖共享服务，在其被禁用时不可用。

有关共享服务的排查，请参阅[故障排除](/zh/docs/troubleshooting)；有关服务端端点，请参阅 [API 参考](https://opencode.ai/v2/docs/api)。

## 路径

打印指定的本地路径，供其他工具使用：

```bash
opencode debug paths db
sqlite3 "$(opencode debug paths db)"
```

可选的选择器接受 `db`、`home`、`data`、`config`、`cache`、`state`、`tmp`、`bin`、`log` 或 `repos`，仅打印路径与一个换行符。数据库路径遵循发布渠道与 `OPENCODE_DB`；相对路径的数据库覆盖值会在数据目录下解析，而 `:memory:` 则按原样输出。该命令不会启动服务器，也不会打开数据库。

省略选择器则显示带标签的全部路径：

```bash
opencode debug paths
```

## 卸载

预览将被删除的文件与安装项：

```bash
opencode uninstall --dry-run
```

运行 `opencode uninstall` 以确认删除。OpenCode 会先停止已注册的后台服务与持久终端，然后再移除全局缓存目录；该目录由 OpenCode 的各版本与渠道共享。会话数据、配置与状态永远不会被删除。

- `--force`（`-f`）跳过确认；用于非交互式删除。
- 通过包管理器安装的，将使用检测到的包管理器。通过 curl 安装的，则会打印用于手动移除可执行文件的最终命令。
