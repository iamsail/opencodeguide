Console 对任何规模的团队都免费，不收取席位费。你只需为实际用量付费，费用从覆盖整个工作区的预付额度中扣除。所有者和管理员在 **Settings › Billing** 中管理账单。

通过[你自己的提供商](/zh/docs/console/providers)产生的用量由提供商计费，而非 Console。

## 添加付款方式

1. 打开 **Settings › Billing**。
2. 在 **Payment methods** 下，点击 **Add**。
3. 选择一种付款方式并完成 Stripe 设置。

支持的付款方式：

- 银行卡
- Link
- 支付宝
- UPI
- 微信支付

使用 **⋯ › Make default** 选择用于自动扣款的付款方式。移除某付款方式可能会中断使用它的自动充值与 Go 续订。

## 充值额度

1. 在 **Credits** 下，点击 **Add credits**。
2. 选择 $10、$50 或 $100，或选择 **Other** 并输入金额。
3. 选择付款方式并点击 **Confirm and pay**。

另需支付 4.6% + $0.31 的手续费，因此购买 $50 实际支付 $52.61，其中完整 $50 计入余额。

## 自动充值

当余额不足时，自动充值会购买额度。

1. 在 **Auto-recharge** 下，点击 **Add rule**。
2. 设置触发扣款的余额阈值和充值金额。
3. 点击 **Save**。

自动充值从默认付款方式扣款，含手续费。若扣款失败，自动充值将关闭，直到你重新设置。

## 查询余额

**Activity** 页面上的 **Billing** 卡片会向所有者和管理员显示余额，点击可打开 **Settings › Billing**。

## 额度用尽时

余额降至零后，付费请求将以 HTTP `402` 失败。余额不会变为负数。

```text
Upstream request failed: Insufficient account funds
```

## 发票

每笔付款都会出现在 **Invoices** 中，显示其状态以及 **Download invoice** 或 **View receipt** 的链接。

| 条目             | 创建方式           |
| ---------------- | ------------------ |
| 余额充值         | 充值额度           |
| 自动充值         | 自动充值           |
| Go 订阅          | 订阅 Go            |
| Go 续订          | Go 按月续订        |
| 月度用量         | 按发票计费         |

## 按发票计费

签订信用协议的工作区可按月开具发票，无需购买额度。请联系支持人员进行设置。

- 用量从信用额度中扣除，而非预付余额。
- 每月发票于 1 日（UTC）开具，14 天后到期。
- 未结发票带有 **Pay now** 按钮。
- 达到信用额度上限或发票逾期时，请求将以 HTTP `402` 失败。

## Go

[OpenCode Go](/zh/docs/console/go) 订阅使用相同的付款方式，并出现在同一发票列表中。在 **Go** 页面开启 **Extra Usage**，可在达到 Go 限额后改用额度支付。
