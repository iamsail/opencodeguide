预算通过策略限制每月支出。所有者和管理员在 **Controls** 中管理它们。

## 预算层级

| 策略对象             | 适用范围                                     |
| -------------------- | -------------------------------------------- |
| 整个工作区           | 全体成员与服务账户的合计支出                 |
| 所有成员             | 每位成员各自的额度，或所有成员共享一份额度   |
| 带以下标签的成员     | 具有所选标签的成员                           |
| 指定成员             | 具体的成员                                   |
| 所有服务账户         | 每个服务账户各自的额度，或共享一份额度       |
| 指定服务账户         | 具体的服务账户                               |

每个请求都必须满足所有适用的预算。较大的额度绝不会覆盖较小的额度。若未设置任何预算，支出不受限制。

## 工作区预算

工作区累计支出达到该预算后，将阻断所有人的请求。

1. 打开 **Controls** 并点击 **Add policy**。
2. 选择 **Entire workspace**，并添加 **Budget** 规则。
3. 输入以美元计的每月上限，然后点击 **Save**。

## 成员预算

在策略中选择 **All members**，可为每位成员提供月度额度，或让整组共享一份额度。选择具体成员或标签，可覆盖更小的群体。

若要为单个人设置预算：

1. 在 **Settings › Members** 中打开该成员。
2. 点击 **Create budget policy**，打开构建器并已选中该成员。
3. 输入金额并点击 **Save**。

其成员页面会列出适用的策略。若全部成员预算也覆盖该成员，则两项限制均会生效。

## 服务账户预算

在 **Controls** 中选择 **All service accounts** 或 **These service accounts**，添加 **Budget** 规则，并设置单独或共享的月度额度。该策略覆盖这些账户的每一个密钥。

## 金额与重置

- 金额以美元计，最多保留两位小数。
- 预算于每月 1 日 00:00 UTC 重置。
- `$0` 预算会阻断所有计入预算的支出。
- 新增或修改预算时，当月已记录的支出仍计入其中；额度不会因此重置。

## 计入范围

默认情况下，预算覆盖 **All spend**。你可以将其限定为所选模型；此后仅这些模型计入预算，可为整组设置一份额度，或为每个模型单独设置额度。

| 支出                                                           | 是否计入预算           |
| -------------------------------------------------------------- | ---------------------- |
| Console 付费模型                                               | 是                     |
| [你自己的提供商](/zh/docs/console/providers)上设置了价格的模型 | 是，按配置价格计入     |
| [网络搜索](/zh/docs/console/websearch)                         | 是，计入全部支出预算   |
| 免费模型                                                       | 否                     |
| 套餐内的 [Go](/zh/docs/console/go) 用量                         | 否                     |
| 使用额度支付的 Go 额外用量                                     | 是                     |

## 达到预算时

新的请求将以 HTTP `429` 失败，直到预算重置或所有者、管理员提高额度。响应会指明策略预算失败，但不会点名具体预算。在 **Activity › Logs** 中打开该请求，可查看阻断它的策略。

```text
Upstream request failed: Policy budget exceeded
```

预算在请求开始时检查。已在进行中的请求会执行完毕，因此支出可能略高于上限。

## 跟踪支出

每位成员都可在 **Activity** 上查看自己的支出与限额。打开 **My usage** 可进入 **Activity › Overview**，其中包含预算详情与重置日期。

所有者和管理员可从支出图表打开 **Activity › Usage**。它按天、模型与人员细分费用，**Export usage** 按钮会将最近 7、30 或 90 天的每日合计以 CSV 下载。
