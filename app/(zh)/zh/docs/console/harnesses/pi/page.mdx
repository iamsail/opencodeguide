[Pi](https://pi.dev) 内置了 OpenCode 的按量付费与 Go 提供商。它会为每个付费或 Go 模型选择正确的 API。免费层级的聊天模型需要 OpenCode，Pi 会返回 HTTP `403`。

| 提供商 | 套餐 |
| ------------- | ------------- |
| `opencode` | 按量付费 |
| `opencode-go` | Go |

## 配置

两个提供商都从 `OPENCODE_API_KEY` 读取密钥。创建一个[个人 API 密钥](/zh/docs/console/harnesses#get-an-api-key)。

```bash
export OPENCODE_API_KEY="oc_sk_..."
pi --model opencode/claude-sonnet-5-5
```

你也可以在 Pi 中运行 `/login` 并选择提供商。Pi 会将密钥存储在 `~/.pi/agent/auth.json` 中。

```text
/login opencode
```

## Go

使用 `opencode-go` 提供商，并提供来自具有 [Go](/zh/docs/console/go) 订阅的工作区的密钥。

```bash
pi --model opencode-go/kimi-k3
```

## 模型

以 `<provider>/<model-id>` 的形式选择模型，模型 ID 来自 [Console](/zh/docs/console/models#endpoints) 或 [Go](/zh/docs/console/go#endpoints) 表格。使用 `--list-models` 列出 Pi 已知的模型。

```bash
pi --list-models opencode-go
```

在 `~/.pi/agent/settings.json` 中设置默认值，或在 `/model` 选择器中按 `Ctrl+S`。

```json title="~/.pi/agent/settings.json"
{
  "defaultProvider": "opencode-go",
  "defaultModel": "kimi-k3"
}
```

当新的 Console 模型尚未出现时，运行 `pi update --models`。

## Console MCP

Pi v0.99.0 及更高版本支持 MCP。添加 [Console MCP](/zh/docs/console/harnesses#console-mcp) 服务器，然后从浏览器登录。

```bash
pi mcp add opencode-console --url https://opencode.ai/console/mcp
pi mcp login opencode-console
