Console 为已连接的 OpenCode 用户提供托管网络搜索。工作区所有者或管理员可为工作区一次性启用该功能，无需向成员分发单独的搜索提供商密钥。

每次成功搜索的费用为 **$0.01**，计入工作区余额与成员支出限额。

## 启用

1. 以工作区所有者或管理员身份登录 [Console](https://opencode.ai/console)。
2. 打开 **Integrations**，在 **Hosted Web Search** 上点击 **Set up**。
3. 点击 **Enable**。

随后，每位成员使用 `/connect` 将 OpenCode 连接到工作区。

```text
/connect
```

工作区配置会选择 **OpenCode Web Search** 作为默认提供商。成员无需设置 `websearch.provider` 或添加提供商 API 密钥。若成员自行设置了 `websearch.provider`，则保留该选择。

## 搜索

在提示中向 OpenCode 询问最新信息。搜索在 OpenCode 中执行，而不是在 Console 的交互页面中执行。

```text
Find the latest Bun release and summarize the changes with source links.
```

托管提供商会搜索公共网络并返回最多八条结果。OpenCode 使用这些结果回答提示并引用来源。

参阅[网络搜索指南](/zh/docs/configure/websearch)以配置权限或禁用该工具。

## 账单

搜索返回有效结果集后，Console 收取 **$0.01**。失败的搜索和受速率限制的搜索不计费。

网络搜索费用在 **Activity › Usage**、**Activity › Overview**、成员活动、发票和 CSV 导出中与模型用量分开展示。适用的全支出预算策略包含网络搜索费用。

## 隐私

托管网络搜索实行零数据保留。Console 及其托管搜索提供商处理每次查询及其结果时不会存储其内容。
