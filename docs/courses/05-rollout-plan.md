# 05 · 分期上线路线图

## 0. 总览

| 阶段 | 时间 | 目标 | 关键交付 | 收款状态 |
| :--- | :--- | :--- | :--- | :--- |
| **P0 基建与预售** | 第 0-2 周 | 页面先上线，验证需求 | 课程目录/详情/感谢页、Stripe 链接脚本、等待名单、埋点 | 可开（可选） |
| **P1 首发成交** | 第 3-6 周 | 跑通真实收款与交付 | 正式 Payment Link、优惠码、邮件自动化、退款政策 | 正式收款 |
| **P2 会员中心** | 第 7-12 周 | 提升完课率与复购 | 登录、订单/权益、播放页、进度、自助重发 | 订阅可选 |
| **P3 规模化** | 第 3-6 月 | 提高 LTV 与客单价 | 订阅、企业采购、联盟、训练营、A/B | 多元收入 |

> 原则：每个阶段都必须能独立产生收入或减少退款，不为了「完整」而推迟上线。

## 1. P0 · 基建与预售（第 0-2 周）

### 范围（本次代码已实现）

- 中英双语课程目录页、详情页、付款成功页
- 4 门课程 + 全站通的数据与文案
- Stripe Payment Link 生成脚本与链接解析（未配置时降级）
- 等待名单表单（端点可配置，默认跳联系页）
- `Course` 结构化数据、hreflang、sitemap
- GA4 `begin_checkout` 埋点
- 导航、页脚、首页入口

### 需要人工完成的动作

1. Stripe 账户准备（若还没有，先用 Paddle 预售或直接人工收款）
2. 用测试密钥生成 Payment Link，跑一遍测试卡
3. 准备交付物：视频托管链接、模板仓库、社群二维码
4. 配置 `NEXT_PUBLIC_COURSE_WAITLIST_ENDPOINT`（Formspree / Buttondown 均可）
5. 上线后 7 天观察留资率

### 验收标准

- [ ] `/zh/courses` 与 `/en/courses` 可访问，移动端布局正常
- [ ] 4 个详情页 + 全站通详情页正常，课程切换无 404
- [ ] 未配置 Stripe 的课程按钮不报错，跳到等待名单
- [ ] 配置测试链接后，点击可进入 Stripe 测试结账页
- [ ] 支付成功后跳回感谢页并显示课程名
- [ ] 页面无 console 报错、无 hydration 警告
- [ ] sitemap 包含课程页、不包含感谢页
- [ ] `next build` 静态导出成功

### 风险与缓解

| 风险 | 缓解 |
| :--- | :--- |
| Stripe 账户未就绪 | 先上等待名单，页面价值不依赖支付 |
| 课程内容未录完 | 详情页标注「已更新模块」，不要标注未完成的内容 |
| 留资率低 | 优先改标题与 Hero，再考虑换课程 |

## 2. P1 · 首发成交（第 3-6 周）

### 范围

- 正式（live）Payment Link，绑定真实价格
- 早鸟优惠码（限时、限量），首页/详情页展示
- 邮件自动化：付款成功 → 开通邮件（观看链接、模板仓库、社群邀请）
- 退款政策页 `/refund-policy`（中英）
- 发票：Stripe Invoice 自动发送；企业客户人工开票
- 客服话术与 FAQ 补充真实问题
- 内容：至少一门课完成全部课时

### 验收标准

- [ ] 真实小额订单（$1 测试 SKU 或全额）跑通并可退款
- [ ] 开通邮件 10 分钟内到达，链接可打开
- [ ] 退款政策页与页面承诺一致
- [ ] Stripe Dashboard 可按 `client_reference_id` 筛出课程订单
- [ ] 每日订单检查有负责人（避免漏发交付）
- [ ] 首周退款率 < 5%

### 关键指标（P1 结束）

| 指标 | 目标 |
| :--- | :--- |
| 目录页 → 详情页 点击率 | > 30% |
| 详情页 → 购买点击率 | > 4% |
| 购买点击 → 支付成功 | > 50% |
| 首月付费订单 | ≥ 20 |
| 退款率 | < 5% |

## 3. P2 · 会员中心（第 7-12 周）

### 为什么必须做

Payment Link 无法回答三个问题：谁买了、买了能不能看、退款后有没有回收权限。当课程数量 > 3 或开始做订阅时，这三点会变成客服灾难。

### 范围

- 引入服务端：Cloudflare Worker（或 Vercel Function）+ Supabase
- Checkout Session 替换 Payment Link（新流量），Webhook 写入 `orders` / `entitlements`
- 邮箱登录（Magic Link），按邮箱合并历史订单
- 课程播放页：视频托管（Mux / Cloudflare Stream）+ 防盗链 + 进度记录
- 退款自动回收权益；拒付标记
- 自助：重发链接、换绑邮箱、申请退款

### 技术选择

| 需求 | 方案 | 理由 |
| :--- | :--- | :--- |
| 认证 | Supabase Auth Magic Link | 无需密码，邮箱天然匹配订单 |
| 数据库 | Supabase Postgres | 免费额度足够，RLS 可控 |
| 服务端 | Cloudflare Worker | 与静态站解耦，冷启动快，成本低 |
| 视频 | Cloudflare Stream / Mux | 防盗链、自适应码率、字幕 |
| 邮件 | Resend / Postmark | 事务邮件到达率 |

### 验收标准

- [ ] 新订单 100% 通过 Webhook 入库（含重放测试）
- [ ] 退款后 1 分钟内失去访问权限
- [ ] 未购买用户无法访问视频地址（直链也无效）
- [ ] 支付成功后自动登录或一键登录
- [ ] 历史订单可按邮箱补齐权益

## 4. P3 · 规模化（第 3-6 月）

- **订阅制**：$19/月或 $149/年解锁全部课程与新内容（适合更新频繁的课程）
- **企业采购**：多席位、统一发票、内训版（客单价最高）
- **联盟分销**：Stripe Coupon + 独立推广链接 + 30% 佣金
- **训练营**：直播 + 作业 + 结营项目，定价 $800-1500
- **A/B 测试**：Hero 标题、价格锚点、CTA 文案（每次只测一个变量）
- **内容扩张**：Stripe 深度实战、AI Agent 产品化

## 5. 指标看板（北极星与护栏）

**北极星：每月净收入（扣除退款与手续费）。**

| 层级 | 指标 | 采集方式 |
| :--- | :--- | :--- |
| 流量 | 课程页 PV / 来源 | GA4 |
| 转化 | 详情页 CTR、购买点击率、支付成功率 | GA4 + Stripe |
| 收入 | 订单数、客单价、ARPU | Stripe + 订单表 |
| 留存 | 完课率、复购率、社群活跃 | 播放页 + 社群 |
| 护栏 | 退款率、拒付率、客服响应时长 | Stripe + 邮件 |

**预警线：** 退款率 > 8%、拒付率 > 1%、支付成功率 < 40%，任一触发即暂停投放，先修链路。

## 6. 运营节奏

| 周期 | 动作 |
| :--- | :--- |
| 每日 | 检查新订单与交付邮件；回复咨询 |
| 每周 | 社群问题汇总进 FAQ；查看漏斗异常页 |
| 每月 | 收入/退款复盘；更新课程页数据；发布更新日志 |
| 每季度 | 课程内容更新；价格与优惠策略复盘；决定是否开新课程 |

## 7. 预算（月度，估算）

| 项目 | 成本 |
| :--- | :--- |
| 托管（Vercel/Cloudflare 静态） | $0-20 |
| 视频托管（P2 起，按流量） | $20-100 |
| Supabase / Worker（P2 起） | $0-25 |
| 邮件服务 | $0-20 |
| 域名与杂项 | $5 |
| **合计** | **$25-170** |

收入侧成本：Stripe 手续费约 2.9% + $0.30/笔（跨境卡可能更高），退款手续费不退。

## 8. 决策点（Go / No-go）

| 时点 | 判断 | 数据门槛 | 不达标时 |
| :--- | :--- | :--- | :--- |
| P0 结束 | 是否继续录制 | 7 天留资率 ≥ 3%，或 ≥ 50 个邮箱 | 改标题与渠道，再等 7 天 |
| P1 结束 | 是否投入 P2 | 首月 ≥ 20 单且退款 < 5% | 先优化详情页与定价，不急着做会员中心 |
| P2 结束 | 是否做订阅 | 完课率 ≥ 30%，复购/推荐 ≥ 10% | 先补内容与交付，订阅会放大差评 |
| P3 中 | 是否扩品类 | 单课月收入稳定 ≥ $3,000 | 收缩到 2 门课做深 |

## 9. 与现有站点的关系

- 文档站继续承担 SEO 与信任建设，不改成销售页。
- 课程页从文档页获取内链（P1 起在相关文档底部加「系统学习」入口，注意不要影响阅读体验）。
- 所有课程页共享现有布局、主题、分析脚本，不引入第二套设计系统。
