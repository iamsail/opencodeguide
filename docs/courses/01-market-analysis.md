# 01 · 市场与定位分析

> 结论先行：这门生意不是「卖视频」，而是把本站已经积累的**技术信任 + 工程方法**，打包成可执行、可验收的能力交付。课程板块的竞争对手不是其他文档站，而是「工程师在深夜自己摸索的时间」。

## 1. 为什么现在做课程

现有站点是 OpenCode / AI 编程的中英双语文档站，流量结构和收入结构都有明显问题：

| 现状 | 问题 | 课程板块如何解决 |
| :--- | :--- | :--- |
| 流量依赖工具热度 | OpenCode / Claude Code 的搜索热度波动大，广告单价低 | 课程是高客单、可复购、不受单次搜索波动影响的收入 |
| 内容同质化 | 文档类内容容易被官方文档替代 | 课程卖的是「顺序、取舍和踩坑记录」，文档替代不了 |
| 用户只读不留下 | 没有账号、没有邮件列表、没有第二次触达 | 购买即获得邮箱，形成可运营的用户资产 |
| 广告收入天花板低 | AdSense 单价按地域和内容类型，技术类偏低 | 同一份流量，课程转化带来的 ARPU 高一个数量级 |

一句话：**文档负责获客，课程负责变现，社群负责复购。**

## 2. 目标人群与 Jobs To Be Done

课程面向四类人，付费动机差异很大，因此课程内容按「能力缺口」而不是「技术栈」来划分。

### 2.1 画像

| 画像 | 典型状态 | 最痛的事 | 愿意为什么付钱 | 价格敏感度 |
| :--- | :--- | :--- | :--- | :--- |
| **A. 想提效的程序员** | 会用 ChatGPT，但 AI 写的代码要返工 | 不知道如何让 AI 遵守项目规范；上下文给不对；怕它改坏代码 | 一套能直接抄的规则/命令/模板，节省试错时间 | 中（¥300-800） |
| **B. 独立开发者** | 能写代码，做过几个 side project，没赚到钱 | 选题靠猜、上线总拖延、不会接支付、不知道怎么获客 | 从 0 到收款的完整清单 + 支付集成避坑 | 中高（¥600-2000） |
| **C. 跨境电商卖家（有技术背景）** | 平台店利润被压缩，想做独立站 | 支付被拒、物流成本算不清、VAT/合规看不懂 | 一次做对，少交学费 | 高（¥1500-6000） |
| **D. 出海产品/增长负责人** | 有产品，依赖投放，自然流量起不来 | 多语言架构混乱、技术 SEO 没做对、内容投入看不到回报 | 可量化的增长方法 + 站点体检 | 高（公司报销） |

### 2.2 JTBD（用户真正想完成的任务）

1. 「当我要让 AI 改一个陌生模块时，我想让它先读懂规则再动手，这样我不用逐行 review。」
2. 「当我有一个想法时，我想在两周内验证有没有人愿意付钱，这样我不会白做三个月。」
3. 「当我要收海外客户的钱时，我想一次把支付、税务、退款处理对，这样我不会被拒付和封号。」
4. 「当我的站点有内容却没人来时，我想知道哪一步做错了，而不是继续堆文章。」

课程标题、卖点和模块顺序都应直接回答上述任务，而不是罗列技术名词。

## 3. 竞品与价格带（2026 年公开市场观察）

价格区间来自公开课程页与社区讨论的常见区间，用于**定价锚定**，不是精确统计。

| 类型 | 代表 | 常见价格 | 优点 | 缺点 / 我们的机会 |
| :--- | :--- | :--- | :--- | :--- |
| 国内技术专栏 | 极客时间、掘金小册 | ¥99-499 | 便宜、体系化 | 偏概念，缺少可运行模板与真实支付链路 |
| 训练营 / 陪跑 | 各类出海训练营 | ¥2000-8000 | 有答疑和社群 | 质量方差大，交付重，退费纠纷多 |
| 海外独立课程 | Gumroad / Indie Hackers 作者课 | $49-299 | 案例真实 | 中英混杂、支付与合规默认美国语境 |
| 电商培训 | 跨境培训机构 | ¥3000-20000 | 资源对接 | 重销售、轻工程，技术背景的人反感 |
| 免费内容 | YouTube / 官方文档 | ¥0 | 覆盖广 | 没有顺序、没有验收标准、时间成本最高 |

**差异化定位（必须同时成立）：**

1. **工程可信度**：本站是长期维护的技术文档站，讲错会反噬，因此内容天然偏严谨。
2. **可执行交付物**：每门课都有模板仓库、检查清单、脚本，而不是只有视频。
3. **真实收款链路**：课程本身就跑到 Stripe 上，支付、税务、退款都自己踩过。
4. **双语能力**：中文讲透，英文材料可直接给海外客户/团队用。

## 4. 需求验证（上线前 2 周即可做）

不验证就录课，是最大的沉没成本。建议按以下顺序，成本从低到高：

1. **搜索验证**：在 Google / Bing 查「opencode 教程」「独立开发者 stripe」「跨境电商 独立站 支付」「多语言 seo hreflang」，看是否有稳定搜索量与商业内容（有广告投放说明有商业价值）。
2. **社区验证**：在 Reddit（r/SideProject、r/SaaS、r/ecommerce）、V2EX、即刻、X 搜索同类问题，统计 2 周内重复出现的问题，直接对应到课程模块。
3. **落地页验证**：课程详情页先上线（本次实现已支持），用「加入等待名单」收集邮箱；7 天内留资率 > 3% 视为需求成立。
4. **预售验证**：开放早鸟价（真实收款），14 天内 ≥ 10 单即可覆盖首门课的制作成本，再决定是否继续投入。
5. **访谈验证**：对 5 个留资用户做 20 分钟访谈，问「你最近一次为这个问题花了多少时间/钱」。

> 反指标：如果详情页访问量高但留资率 < 0.5%，说明卖点没打中，先改文案和标题，不要急着录课。

## 5. 商业模式与定价

### 5.1 产品阶梯

| 层级 | 形态 | 目的 | 价格带 |
| :--- | :--- | :--- | :--- |
| 引流 | 文档、免费试听、工具脚本 | 建立信任、收集邮箱 | ¥0 |
| 入门 | 单门课（Single） | 首单转化 | $79-179 |
| 主力 | Pro 版（模板仓库 + 答疑 + 1:1） | 提升客单价与完课率 | $149-299 |
| 打包 | 全站通 All-Access | 提高 LTV，降低选择成本 | $399 |
| 高阶 | 训练营 / 企业内训（Phase 3） | 高客单、强交付 | $800-3000 |

### 5.2 定价原则

1. **三层锚定**：单课价 → Pro 价 → 全站通价，价差控制在 1.8-2.5 倍，避免中间层无人选。
2. **早鸟折扣 30-40%**，用 `compareAtUSD` 展示原价；折扣有明确截止时间（Stripe 优惠码可设过期）。
3. **捆绑价 = 单课总价 × 0.82**：本仓库四门课单课合计 $486，全站通 $399（约 82 折）。
4. **升级抵扣**：已购单课补差价升级全站通，减少「等等党」。
5. **美元定价 + 人民币参考**：Stripe 结算以 USD 为主，页面展示 `≈¥` 降低决策成本，但明确「以美元结算」。

### 5.3 收入模型（用于判断投入是否合理）

```
月收入 = 课程页访问量 × 详情页点击率 × 购买转化率 × 客单价 + 复购
```

保守假设（首季度，单一中文流量）：

| 指标 | 保守 | 基准 | 乐观 |
| :--- | :--- | :--- | :--- |
| 课程页月访问 | 3,000 | 8,000 | 20,000 |
| 详情页点击率 | 35% | 40% | 45% |
| 购买转化率 | 0.8% | 1.5% | 2.5% |
| 客单价 | $90 | $110 | $130 |
| **月收入** | **≈ $756** | **≈ $5,280** | **≈ $29,250** |

> 这组数字的意义不是预测，而是告诉你：**转化率每提升 0.5 个百分点，比多写 10 篇文章更值钱**。因此 Phase 1 的重点是落地页质量与支付链路，而不是内容数量。

## 6. 风险与对策

| 风险 | 影响 | 对策 |
| :--- | :--- | :--- |
| 内容被盗版/二次分发 | 收入流失 | 视频水印、账号绑定、模板仓库私有、定期换链接 |
| Stripe 账户审核 / 冻结 | 无法收款 | 主体合规、KYB 材料齐全、备选 Paddle；不承诺「保证过审」 |
| 课程制作拖延 | 预售用户退款、口碑受损 | 先卖已完成模块；明确上线日期与延期全额退款条款 |
| 内容过时（API 变更） | 差评、退款 | 每季度更新；版本号与更新日志放在详情页 |
| 退款率过高 | 现金流与支付风险 | 7 天无理由但限制「已下载模板」；Pro 版 1:1 前置沟通 |
| 流量依赖单一工具 | 需求随工具热度波动 | 内容向「方法论」倾斜（规则工程、支付、SEO），降低工具绑定 |

## 7. 本阶段结论

- 先做**两门已可交付的课**（AI 编程、独立开发），第三门（跨境电商）用**预售**验证需求，第四门（SEO）作为低价引流课。
- 定价用「单课 / Pro / 全站通」三层，先跑通 Stripe 支付与交付，再考虑会员订阅。
- 课程板块的第一优先级不是「更多课程」，而是**详情页转化率**与**支付成功率**。
