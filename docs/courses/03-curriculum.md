## 2. 课程 01 · AI 编程实战：用 OpenCode 组建你的 AI 工程团队

- **slug**：`ai-coding-workflow`
- **时长 / 课时**：12 小时 / 24 节
- **难度**：全阶段
- **前置要求**：能读写代码、会命令行；无需 AI 工具经验
- **核心承诺**：学完能稳定产出可合并的 PR，而不是只会补全

### 模块与课时

**模块 1 · 心智模型与环境搭建（4 节）**
1. 本地优先 vs 云端助手：安全边界、成本结构与适用场景
2. 安装 OpenCode 并跑通第一个会话（macOS / Windows WSL / Linux）
3. 模型提供商配置：Anthropic、OpenAI、DeepSeek、Ollama 的组合策略
4. 把 token 成本压下来的 6 个开关（路由、缓存、上下文裁剪）

**模块 2 · 规则工程：让 AI 遵守你的代码库（5 节）**
1. AGENTS.md 的分层写法：项目级 / 目录级 / 任务级
2. 把团队约定翻译成机器可执行的规则（命名、测试、提交信息）
3. Plan Mode 与 Spec-first：先让 AI 写方案，再让它写代码
4. 三种反模式：过度上下文、伪需求、无验收标准的任务
5. 验收环节：如何让 AI 自己跑测试并解释失败原因

**模块 3 · 智能体编排：从单线程到「小型团队」（5 节）**
1. 子智能体（Subagent）的职责划分：规划、实现、评审、测试
2. Skills 复用：把团队经验沉淀成一次安装、处处可用
3. 自定义命令：把高频工作流压缩成 /review、/ship、/migrate
4. 权限与沙箱：哪些目录绝不允许 AI 写入
5. 多智能体协作实战：一个功能从需求到 PR 的完整流水线

**模块 4 · MCP 工程化：把外部系统接进来（5 节）**
1. MCP 协议原理与三类消息：tools、resources、prompts
2. 数据库 MCP：只读查询、Schema 自省、生成迁移脚本
3. Playwright MCP：让 AI 自己点网站、复现前端 Bug
4. 封装内部 API 为 MCP 服务（30 行代码的最小实现）
5. MCP 的安全红线：凭证管理、权限最小化、审计日志

**模块 5 · 真实项目实战（4 节）**
1. 实战 A：给无测试的遗留模块补测试并安全重构
2. 实战 B：一次性完成「注册 → 支付 → 邮件」全栈功能
3. 实战 C：跨仓库改动：前端改字段、后端加接口、文档同步
4. 代码评审自动化：让 AI 按团队 checklist 出评审意见

**模块 6 · 团队落地与治理（4 节）**
1. 团队规范：允许/禁止清单、Code Review 责任划分
2. CI 集成：AI 生成代码的自动化质量门禁
3. 安全与合规：代码外发、私有化部署、审计留痕
4. 成本治理：按月复盘 token 开销与产出比

### 交付物
- 3 套模板：单仓库规则、多子智能体编排、MCP 服务封装
- 32 项「AI 编码工作流自查表」
- 团队 AI 编码规范（可改公司名）
- token 预算模型表

### 制作要点
每节课按「一个错误示范 → 一个正确工作流 → 可复制的命令」三段式；模块 5 全程录屏，保留真实的报错与修正过程。

## 3. 课程 02 · 独立开发者出海：从 0 到 1 上线并收款的 SaaS

- **slug**：`indie-saas-launch`
- **时长 / 课时**：16 小时 / 30 节
- **难度**：进阶
- **前置要求**：React / TypeScript 基础；有至少一个已完成的小项目
- **核心承诺**：学完能独立上线一个能收款的 SaaS，并知道前 10 个付费用户从哪来

### 模块与课时

**模块 1 · 选题与需求验证（4 节）**
三种产品形态 / 痛点清单法 / 5 个页面验证需求 / 预售与等待名单

**模块 2 · 最小技术架构（5 节）**
技术选型标准 / Postgres + ORM / 认证方案对比 / 部署与免费额度边界 / 可观测性一次配好

**模块 3 · 多租户与权限（4 节）**
租户模型选择 / 组织与成员 / 角色-资源-动作 / 额度与限流

**模块 4 · Stripe 收款与定价（7 节）**
账户与 KYB / Checkout vs Payment Link / 订阅与按用量计费 / Webhook 与订单状态机 / 优惠码与退款 / 税务与多币种 / 对账

**模块 5 · 上线（5 节）**
域名与邮件认证 / 落地页结构 / 法务三件套 / 真实测试卡全链路演练 / 灰度与回滚

**模块 6 · 首批用户与增长（4 节）**
冷启动渠道 / 内容 SEO 对比文 / 定价页 A/B 与挽留 / 升级触发的 4 个时机

**模块 7 · 运营与合规（4 节）**
退款与拒付 / GDPR/CCPA 最小实现 / 收入记账与税务 / 海外主体的时机

### 交付物
- SaaS 启动模板：Next.js + 认证 + Stripe 订阅 + 额度中间件
- 定价页与 5 种定价模型对照表
- 60 项上线检查清单
- 20 个冷启动渠道清单

### 制作要点
模块 4 是本课的核心，用**同一个演示项目**从 0 接到「支付成功 → 开通权益」；Webhook 部分演示本地 `stripe listen` 与幂等处理。

## 4. 课程 03 · 跨境电商独立站：建站 · 支付 · 合规 · 增长

- **slug**：`cross-border-store`
- **时长 / 课时**：18 小时 / 32 节
- **状态**：预售，预计 2027-01 上线（已交付模块 1-2 先行版）
- **前置要求**：基本建站或开发能力；无电商经验可学，但需多花时间在模块 1-2
- **核心承诺**：一次把支付、物流、合规做对，少交学费

### 模块与课时

1. **出海电商全景与选品（4 节）**：平台店 vs 独立站 / 目标市场差异 / 选品数据源 / 含关税运费的毛利测算
2. **建站选型与落地（5 节）**：Shopify / Shopline / WooCommerce / Next.js 决策树；Checkout Extensibility；自建站方案；Core Web Vitals；多语言多币种结构
3. **支付与风控（6 节）**：Stripe 跨境收款；PayPal / 支付宝 / 微信；多币种与汇率；3DS/SCA；风控与拒付预防；退款与争议
4. **物流与履约（4 节）**：头程/尾程/海外仓成本模型；物流商与时效；DDP vs DDU；退货方案
5. **合规与税务（5 节）**：VAT/OSS/销售税；隐私合规；商品认证（CE/FCC/电池/化妆品）；广告合规；法务页模板
6. **AI 内容与素材（4 节）**：多语言商品文案；AI 图片与实拍结合；短视频脚本与批量剪辑；素材 A/B
7. **广告与转化（3 节）**：Meta/Google/TikTok 冷启动；素材测试矩阵；漏斗诊断与弃购挽回
8. **数据与复购（3 节）**：AOV/CAC/LTV/退款率；会员与捆绑；UGC 与季度复盘

### 交付物
- 78 项独立站上线检查清单
- 支付渠道费率与推荐组合表
- 广告素材脚本模板 + AI 生产工作流
- 中英双语客诉/退款话术库

### 预售策略
先交付模块 1-2 的先行版（选品与建站），用真实店铺数据做案例；上线日期写入详情页，延期 30 天全额退款。

6. **度量与迭代（4 节）**：Search Console 报表 / GA4 事件与归因 / 6 个判断指标 / 季度复盘排期

### 制作要点

## 7. 制作与更新规范

### 单节课结构（8-15 分钟）
1. 0-30 秒：本节要解决的问题 + 最终效果演示
2. 30 秒-2 分钟：为什么这样做（原理/取舍）
3. 主体：录屏操作，保留真实报错与修正
4. 结尾：可复制的命令/清单 + 下一节预告
5. 描述区：命令、代码、参考链接

### 质量标准
- 每节课至少一个「可复制产物」（命令、模板、检查项）
- 视频必须带章节标记与字幕（中英双语字幕优先）
- 代码示例必须可运行，仓库打 tag 对应课程版本
- 出现工具大版本变更时，7 天内更新受影响课时

### 更新节奏
- 每周：社群答疑汇总成 FAQ
- 每月：检查一次外部 API/工具变更
- 每季度：更新一次模板仓库依赖，发布课程更新日志
